# 商品を読む（台本を書く前に、かならずここから）

台本は、商品の資料に書いてある事だけで書く。ここは、**どのファイルを・何のために・どこまで読むか**と、読み終えた印の**「商品の理解メモ」**の形を決める。

## 1. 商品のフォルダと、読み方の基本
- 場所：`<商品名>/`（ダッシュボードの商品の id との対応は `（アプリのダッシュボード）` の商品名で確かめる）
- フォルダの形はどの商品も同じだが、**無いファイルがある商品も、章の題がちがう商品もある。** 下の表の章の名前は「中身」を言っている。ファイルを開いたら、先に章の題を全部見て、同じ中身の章を読む。見つからなければ、メモの 11 に書く
- `.bak` の付いたファイルは読まない

**原因の1文が、資料に書いていない時の決め方**
1. 資料から、事実を3つ取る：(ア) 困り事が出る時、見えない所で、何がどうなっているか（`D` の土台）(イ) 商品が、何に・何をするか（`A` の仕組み）(ウ) 今の対策が、何に届いていないか（`D` の欠点・`E`）
2. **(イ) で商品が変えている物の、今の状態**を、原因にする。`中身の質` 2-2 の形（どこの・何が・どうなっている）で1文に。(ア)(ウ) と同じ物を指しているかを確かめる
3. 言葉は、資料の言葉で。新しい名前・新しい仕組みを足さない
4. (ア) と (イ) が同じ物を指さない時は、書かずに聞く


## 3. 段階で選んで読む物（指定された段階の行だけ）
長いファイルは、全部は読まない。章の題を先に見て、下の中身の所だけ読む。

| 段階 | 読む所 | 何を取るか |
|---|---|---|
| ① 気づいていない | `B_市場と悩みの地図` の、市場の数字・悩みの割合・だれが一番困っているか・何かのせいにしている文。`D1`・`D2` の「共通する土台」 | 「こんなものだ」と思っている人の言葉、問題の大きさ、放っておくとどうなるか |
| ② 問題に気づいている | `B` の、お客さんの言葉（原文）・何かのせいにしている文・買う時の壁・（あれば）仕組みの出どころ。`D1`・`D2` の「共通する土台」 | 悩みを言う時の言葉、まちがって信じている原因、本当の原因の材料 |
| ③ 解決策を知っている | `D1`・`D2` の「共通する土台」と、**今回の相手の章**（何をしている物か・仕組み上の欠点・失敗の実例・お金と手間・効く場合）。`D_検証結果` の、その対策の行（理由・直し方の列も）。`B` の、その対策を使っている人の原文 | 今の対策がしている事と、足りない物。どこまでは効くかの線引き。使っている人の言葉 |
| ④ 商品を知っている | `C_競合の地図` の、結論・同じ商品の売り手・空いている場所。`A` の値段と保証・できない事。`B` の、同じ種類の商品を使った人の言葉と、買う時の壁 | 見る人が比べている相手、疑っている点（値段・本当に効くか）への答えの材料 |

- `B` の原文は、章の題だけでは拾いきれない。**今回の相手・悩みの言葉でファイルの中を検索して**、ほかの章にある原文も拾う
- 相手が決まっている時は、その相手・その悩みの原文だけでよい。ただし、**その相手が言っていそうな原文は、全部読む**（人物メモの材料。困り事の場面・その時の言葉・何のせいにしているか・こうなりたい）

## 5. 今回の入口の決め方（ここで決めるのは入口まで。1人にするのは `相手を1人に決める.md`）
0. **依頼票がある時**（2026-10-11）：票の「アングル」が入口。票に「相手の指定」（場面・責めている物）があれば、それ。無ければ、アングルのページの J-1（場面・原文）から取る。1人にするのは、今までどおり `相手を1人に決める.md`。下の 1 の「前と違う物にする」は、票でも同じ（票の「ほかの票と変える物」があれば、そこを変える）

2. 指定が無ければ、`F` の段階×悩みの表から、今回の段階のマスを並べ、`F` の pack の表で一番先の物を取る（「順」と書いてなければ、表の上の行・出す週が早い方が先）。**状態が「後で」「ほかの結果を見てから」の物は取らない。商品の主な困り事（概要の1行目の困り事）から外れない。** 取った相手が「使った物の記録」でもう使った切り口でも、**相手はそのまま**にして、1 と同じように中身を変える（同じ困り事の中で、場面・否定する思いこみを別の物にする。**否定する思いこみが、段階と合う行で一番多い物しか無い時は、その物のまま、言い方と場面を変える**）。**取ったマスが「いろいろ試した人」のように対策がいくつも並ぶ時（段階③）は、主な困り事について、お客さんの原文で一番多く試されている対策1つを、今回の敵にする**（2026-10-11）
3. 順が書いてない・その段階のマスが pack の順に無い・状態が「後で」の物しか無い時は、**自分で決める**：その段階のマスと、お客さんの原文から、一番よく居そうな入口を1つ取る（聞かずに進め、返事の頭の「相手」に書く）

## 5-2. 資料に無い切り口を渡された時（商品の資料が、別の困り事を中心に作ってある時）
（2026-10-11：票のアングルに J のページがある時は、ここに当たらない。小さい基盤は作らず、J を読む。ここは、J のページが無い切り口の時）
切り口の名前（別の困り事・別の体の部分・別の場所や物・別の使い道）を渡されたら、**書く前に、その切り口の小さい基盤を作る**（`相手を1人に決める.md` の 2-4）。商品の事実と原因の仕組みは、商品の資料から取り、その切り口に当てはめる。当てはめた文（資料に無く、自分で書いた仕組みの文）は、理解メモの 11 に一覧にする。**切り口の名前は、作る側の言葉。相手がその言葉を知っているとは限らない**（`相手を1人に決める.md` の 2-2）。
- **その切り口での使い方が、資料に無い時**：資料の使い方に一番近い形（同じ置き方・同じ時間）で書き、**資料に無かった事を、返事の「伝えておく事」に1行で書く**。運営者 が使い方を指定していれば、それを使う。新しい効き目・新しい付属品・数字は足さない
- **結末（放っておいた先）が、その切り口の資料に無い時**：商品の根本原因の線（資料の「原因 → 続くとどうなるか」）を、その切り口の場所に当てはめて言う。別の病気・別の仕組みを持ってこない

## 7. 決まり
- **自社の商品の主張は、前提として使う。** 資料に「判断待ち」「確認待ち」「案」と書いてあっても使ってよい。「使わない」と書いてある物だけ、使わない
- **出どころが弱いだけの事は、欠点として扱わない。** `D_検証結果` で △ の主張は使ってよい（直し方が書いてあれば、その言い方で）。使わないのは × だけ。11 に「出どころが弱い」を並べない（11 は、無い物だけ）
- 無いファイル・無い章は、11 に書く
- **資料に無く、自分で足した事は、全部、出力の「足した事の一覧」に書く**（`templates/出力の形.md`）。足してよいのは：物語・場面の小道具と動作／相手の毎日の場面の絵／たとえ／日の割りふり（スケルトン）／資料の事実をつなぐ「だから」の1文。**足してはいけないのは：資料より強い結果・資料に無い出来事や数字・人の話。** 一覧に書けない物は、台本から消す
- お客さんの言葉は、原文のまま写す（言い直さない）
- 資料どうしが食いちがう時の順：① 運営者 が決めたと書いてある方 ② 日付の新しい方 ③ `使った物の記録` ＞ `05_原稿の決まり` ＞ 基盤（A〜I）。基盤や `05` に例として載っている書き出し・たとえが、記録で使用済みなら、使わない
- 同じ会話の中で同じ商品をもう読んでいても、段階か相手が変わったら 3章を読み直す。`使った物の記録` は毎回読み直す
