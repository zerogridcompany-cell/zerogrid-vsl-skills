# 台本の決まり（1枚。2026-10-21 作り直し・同日 運営者 の OK で本物へ）


**台本の中身の決まりは、この1枚と、寄せ方の1枚だけ。** 決まっているのは「何を伝えるか」と「質」。**どう言うか（文の形・順・言い回し）は、毎回、書き手が決める。**

## 0. 3つの約束
1. **決まった文の形は無い。** 見本や過去の台本の言い回し（「〜の正体です」「することは、1つだけ」「今なら、まだ間に合います」「〜という意味です」「ありがたいことに〜」など）を、毎回の型にしない。同じ言い回しが、前の台本と同じ所に来ていたら、言い直す
2. **伝わる事が先。** 決まりを守るために、意味の通らない文を入れない。入れる訳が言えない文は、入れない
3. **人に見せる試写はしない。** 質は、書き手が書きながら、そして書いた後に1回、自分で見直して作る（7章）

## 0b. 必ず守る物は、これだけ。ほかは全部「道具」
決まりが増えるほど、書き手は決まりを守るために書き、台本が似てくる。だから、**必ず守るのは次の6つだけ**にする。この下の章にある、そのほかの決まり（運びの手札・フックの入り方・場面に入れる一言・「あなたは」・3bの順・例の形 など）は、**良くするための道具**。台本に合わない時・決まりを守ると不自然になる時は、使わない（使わなかった物は書かなくてよい）。
1. 伝える事 a〜h が、どこかで全部伝わっている（順・言い方は自由）
2. 原因の説明が、困り事そのものまで、飛ばさずに届いている（2章）
3. どの文も、遠回しでなく、1秒で分かる。前の文とつながっている（4章・4b）
4. 打ち消すのは、多くの相手が本当に思っている事だけ（1-2・1-2b）
5. フックに、目に浮かぶデスがある（3章）
6. 決まった文の形をくり返さない。前の台本と、運び・語り方・言い回しが同じにならない（0章・1-3）。ただし「普通（王道）」と頼まれた時は、運びと語り方は同じでよく、フック・場面・締めの言い回しで変える

## 0c. 寄せなしで書く時（「寄せなし」と言われた時・映像の型に合う寄せ方が無い時）
寄せ方の1枚は読まない。**この1枚だけで書く。** 寄せ方が決めていた運び・長さは、次で決める。
1. **運び**：指定が無ければ、1-3 の「普通（王道）」の並び。手札から別の運びを選んでもよい。どちらにしても、台本の頭に1行で書く
2. **長さ**：900〜1,100字（空白・改行を除いて数える。声にして約2分半〜3分）。a〜h を落とさずに入りきらない時は、6b の「字数に入りきらない時に外す順」で削る。原因の説明は、困り事に届くまで削らない
3. **書き直し**：決まりどおりに書き終えたら、**4b で必ず頭から書き直す。** 寄せなしの質感は、この書き直しで出る。手本は `研究/見本/2026-10-21_針マット_分かりやすく書き直した版.md`（読むだけ。言い回し・運びは写さない）
4. **何本か同時に書く時**：書き始める前に、1本ずつ「運び」と「フックの入り方」を表に割り当て、全部ちがう物にしてから書く。別々の人（別々の AI）が書く時も、この表を全員に渡す。書き終えたら、表のとおりになっているかを見比べる

## 1. 伝える事（全部入れる。**この表は中身の確かめ表で、話す順ではない**。順は 1-3 の運びで毎回決める）
| # | 伝える事 | 満たした、と言える中身 |

### 1-2b. 打ち消す見立て・場面の問いかけは、多くの相手が本当に思っている事だけ（2026-10-21 運営者 の書きこみの要約：少ない人しか思っていない見立てを打ち消していた。相手が気にしていない物の見た目を問いかけていた）
- 打ち消す見立ては、理解シートで件数の多い物を1つ。少ない見立てを並べて足さない
- 場面で問いかける事・指さす物は、相手がふだん気にしている事だけ。書き手が面白いと思った観察を、相手に問わない

### 1-2. 相手の頭の中を読みちがえない（2026-10-21 運営者 の指摘の要約：相手が思っていない困り事を打ち消したら、「いや、それは困ってない」でその場で離れる。相手の思惑をしっかり理解できるように）
- **打ち消すのは、相手が本当に思っている事だけ。** 相手が思っていない事を打ち消すと、その1文で「私の話じゃない」と離れる
- 相手の頭の中には2つの形がある。**見立て**（「年のせい」「くせかな」）と、**疑問**（「◯◯しても、なんで◯◯なの？」）。理解シートの原文が疑問の形なら、打ち消さない。**その疑問をそのまま言い、その答えとして原因へ進む**
- 相手の困り事は、相手が感じている形で言う。こちらが言いたい結果（におい・汚れ）に、相手の困り事を言いかえない（相手が感じている困り事と、こちらが言いたい結果は、ちがう事がある）
- 確かめ：打ち消す文・疑問の文を、相手に言ったら「そう、それ思ってた」と言うか。「え、そんな事は思ってない」と言いそうなら、書き直す

### 1-3. 運びとフックの入り方を、毎回変える
同じ型ばかりになったのは、①この表の a〜h を上から順に書いていた ②15の心の声を「この順が基本」と読んでいた ③フックの形が「だれの話か＋デス」の1つしかなかった ④見本1本の運びを、みんながまねした ⑤書く前に運びを選ぶ手順が無かった、から。書く前に、次の2つを決めて、台本の頭に1行ずつ書く。
**運び（どの順で、何を軸に話すか）**。手札から選ぶ。手札に無い運びを作ってよい（作ったら、この表に1行足す）
| 運び | 形 |
|---|---|
| 問いを開けて、最後に閉じる | フックで投げた問いの答えを、原因の最後まで引っぱる |
| 当てはまる人は最後まで | 当てはまる症状・場面を3つ並べ、「1つでも当てはまるなら」で引きとめてから原因へ |
| 出来事の途中から | 一番いやな瞬間から始め、なぜそうなったかを巻き戻す |
| 時間をさかのぼる | 「今の困り事は、前の◯◯から始まっている」と時間を戻して、鎖を前から進める |
| みんながしている事 | たいていの人がする手を2〜3並べ、どれも根本に届かない訳を1つずつ外していき、最後に本当の原因。**並べる手は段階に合わせる**：段階②なら毎日のしのぎ方（休む・さする・温める）まで。解決策として買った物（道具・サプリ）を並べるのは段階③の時 |
| 中の目 | 体・物・生き物の中から、今起きている事を実況する |
| 比べる | 平気な時と困る時（家と職場・若い頃と今・休みの日と仕事の日／困り事を起こしている側が生き物や物なら、その生き物・物がうまくいく場所といかない場所）の違いから、原因を見つける |
| 未来から | 放っておいた先の姿を先に見せ、そこから今へ巻き戻す |
| 数字から | 一番驚く数字を先に出し、その数字がなぜ困り事になるかを説明する |
| 1人の物語 | 相手と同じ困り事の1人（年代・場面）に起きた事を、始まりから変わった後まで、物語で語る。原因と商品は、その人が知った事として出る |
| 質問に答える | 相手が心の中で言う質問を3〜4つ、1つずつ答えていく（「なんで◯◯なの？」「◯◯じゃだめなの？」「じゃあ、どうすれば？」）。質問の順が、そのまま話の順になる。番号で運ぶ時は、最初の質問を「まず、1つ目の質問」のように順番の言葉で入る（2026-10-21 運営者） |
| 商品を先に見せる | 商品を使っている場面（変わった後）を最初に見せ、「なぜ、これで◯◯が止まるのか」を逆からたどる |
| 間違い3つ | 相手がよかれと思ってしている間違いを3つ、1つずつ「なぜ間違いか」と一緒に。3つ目で本当の原因に着く。間違いを言った後は、責めずに「楽になるから続けていた事」と受ける |
| 事実をいくつか並べて1つで解く | ふしぎな事実を2〜3並べ、「共通しているのは」で1つの原因を出し、事実を1つずつ解く |
**「普通（王道）」と頼まれた時**
- 語り方は「あなたに語る」、運びは王道の並び（思いこみ → それは外れている → 原因を困り事まで → 今しのいでいる手が届かない訳 → 放っておいた先 → する事と商品 → 変わった後 → 記事へ）。相手の頭の中が疑問の形なら、「思いこみ → 外れている」の所は「疑問 → その答え」にする（1-2）。床や生き物が語る・物語・作り手の目など、尖った語り方は使わない
- 「前と同じにしない」は、運びの形ではなく、フックの言い方・場面・たとえ・締めの言い回しで守る
- 依頼に指定が無い時は、商品の台帳を見て、王道と尖った物をまぜる（尖った物ばかりにしない）

**語り方（だれの目から、だれに向けて語るか）**。毎回「あなた（相手）」に呼びかける・相手の年代や属性を名指すだけにしない。手札：
| 語り方 | 形 |
|---|---|
| あなたに語る | 相手を「あなた」で場面に入れる |
| 1人の人物 | だれか1人（同じ困り事の人）の話として語る |
| 作り手・詳しい人の目 | 作った人・その道の人が、知っている事を話す |
| 中の目 | 体・物・生き物の中や目線から、今起きている事を語る |
| 事実から | だれも名指さず、起きている事・数字・仕組みだけで語る（見る人が自分で「私の事だ」と気づく） |
| 生き物・物の目 | 困り事にかかわる生き物・物・場所（困り事を起こしている側、困り事を受けている物・場所、体の部分）が語る |
- 相手の年代・属性（「50代の方」など）で呼びかけるのは、手札の1つ。毎回しない。だれの話かは、困り事そのものの言葉でも伝わる
**フックの入り方**（3章）。呼びかけ・問い・出来事の途中・数字・知らなかった事実・未来の姿・甘く見ない・逆さ（よかれと思ってしている事が原因）など
- **運びは、前半だけでなく、後半の並びも変える**。前の台本の後半が「原因 → 今の対策を外す → 放っておいた先 → する事 → 商品 → 変わった後 → 記事へ」なら、次は物語・質問・商品から・間違い3つなど、全体の並びが変わる運びにする。台本の頭に「後半の並び」も書く
- **同じ回に何本か書く時は、運びもフックの入り方も、全部ちがう物にする。** 1本だけの時も、台帳と `使った物の記録.md` の直前の3本と、運び・入り方が同じにならないようにする
- この決まりの中の「例の形」の文は、考え方の例。台本にそのまま使わない（そのまま使うと、毎回同じ文になる）
- 見本（`研究/見本/`）は、言葉の分かりやすさの見本。運び・フックの形はまねしない
- 後半の並べ替えの例：商品を原因の直後に出して条件は後から回収する／放っておいた先を最後に置いて締めにする／変わった後の場面を商品より先に見せる／記事への問いを冒頭で開けて最後に渡す。3bの順は道具なので、運びに合わせて組みかえる
- 運びが3bの中身を含む時（「みんながしている事」で別の手を外し終えている等）は、3bを別に足さない
- 「放っておいた先」を先に見せた運び（未来から・フックのデス）では、後でそこへ着く所は短い受けでよい（同じ事を2回くわしく言わない）
- 書いた後、商品の `使った物の記録.md` に、運び・語り方・フックの入り方・締めの並び・「今だけ」の訳（季節など）を1行足す（次の台本が同じにならないため）

## 2. 原因の説明の作り方（質の中心）
- **起きた順に、1文に1つの出来事。** 前の文で起きた事が、次の文の始まりになる。主語は「何が」がはっきりした名前（前の文の物を「この◯◯」「その◯◯」と受けてよい）
- **（道具）原因を言い切る時は、短く強く言い切ってよい**（「原因は、◯◯そのものです」の類。決まった文にはしない）
- **困り事は、たいてい積み重ねで起きる。1回で起きたように聞こえる言い方をしない**（「始まったのは、前の晩です」は、一晩で起きたように聞こえる。「毎晩、少しずつ」と積み重ねで言う。2026-10-21 運営者）
- **今の対策で「楽になる」のを認める時は、なぜ楽に感じるのかと、なぜ原因には届かないのかを、両方言う**（例の形：温めると体全体の血は流れるので楽に感じる。でも、固まった所の中までは流れない。2026-10-21 運営者）
- **困り事を直接起こしている物は、名前で言う**（商品の資料がその仕組みを「言わない」と決めている時は、資料にある仕組みだけで困り事まで届けばよい。名前は道具。痛みを起こす物質なら、その物質の名前を出し、初めて出る所で「何をする物か」を一言）
- **「たまる」「残る」「こもる」を言う時は、なぜ流れ出ない・消えないのかを、その前に言う**（例の形：動かない → 血が流れない → だから、流されずに◯◯にたまる）
- **困り事を直接起こしている物の名前まで言う**（痛みなら、痛みを起こす物質がたまって神経を刺激する／においなら、においのもとができる、の所まで）
- **最後は、困り事そのものに届く。** 途中の出来事（重さが乗る・止まる・縮む）で止めない。「どこが、なぜ痛むのか」「何が、なぜたまるのか」まで言う。原因の説明の最後の1文を読んで、相手が「だから、ここが痛いのか」と言えるか
- **相手が知らない物（膜・脂肪・神経・継ぎ目の中）は、出てきた所で「何か」を短く言う**（どこにあって、ふだん何をしている物か）
- **長さは決めない。** 困り事に届くのに要る分だけ。困り事に近づかない話（名前の由来・細かい作り・へえの寄り道）は入れない
- **原因と、ただの途中の出来事を取りちがえない。** 「◯◯が原因」と言う物は、それが無くなれば困り事が止まる物
- 比べる言葉（少し・前・多い・硬い）には、何と比べてかを付ける

## 3. フック（最初の2〜3文。合わせて60字前後まで）
- **フックは短く、1文目でペインに刺す**。説明・前置き・比べる話の説明はフックでしない（本文で）。比べる・たとえる時も、1文で言い切れる形にする（毎回たとえを使う必要はない）
- **デスは、相手が自分の暮らしで一番こわい事に結ぶ**（「仕事もままならないくらい、体が腐っていく」の方がこわい）。体・物がこわれる絵（腐る・やせ細る・死んでいく）と、相手が一番困る暮らしの結果（仕事がままならない・毎日薬なしでは過ごせない・家族に頼る）を1文でつなぐ。相手が自分に起こると想像できない場面（その場から動けなくなる・振り向けない）だけで終わらせない。確かめ：相手が「それは本当に困る」と言うか
- **フックで問いを投げたら、次の文で必ずその問いを受ける。受けるつなぎは、問いの答えを受ける自然な言葉にする**（「それなら」より「そのままでは」「放っておくと」の方が自然、の類。2026-10-21 運営者）。例の形：「何時間で◯◯になりますか」→「もし◯時間もたないなら、〜」
- **フックの後に、最後まで見させる一言を入れてよい**（「次のどれかに当てはまる人は、手遅れになる前に最後まで見てください」の類。2026-10-21 運営者）。入れるかは運びで決める
- **デスは必ず入れる。ただし文の形を毎回同じにしない**（2026-10-21：「事実＋このままだと〜」の形ばかりになった）。未来の姿・数字・問い・出来事の途中・逆さ、どの入り方の中にデスを入れてもよい
- **（道具）場面に入る前に、見る人を場面に入れる一言を入れてよい**（「こんな朝です」「あなたの毎日を、少し映してみます」の類。言い回しは毎回変える）
- **だれの話か ＋ 目に浮かぶデス。** 細かい場面（時刻・場所・動作）は本文で言うので、フックでは言わなくてよい
- **本当の原因（cの答え）は、フックで言わない**（見る理由が無くなる。答えは、cを積んだ後で）
- 入り方は毎回変える（呼びかけ・宛て名・放っておくと・甘く見ない・中では・問い、ほか何でも）。「最後まで見てください」は入れても入れなくてもよい
- 書く時は、まず強いデスの言葉（何が・どうなる）を3〜5個出して、一番強い物で書く

## 3b. 解決策と、その後（2026-10-21 運営者 の書きこみから。**この節の中の順も、運びで変えてよい**。商品を先に見せる運びなら、条件は後から回収する、など）
- **商品の名前は、急に出さない。** する事を言ったら、その条件（何を・どこまで・どれだけの間）を言い、「手では、その条件を満たせない」と言ってから、「その条件を満たす道具が、◯◯です」と出す
- **する事を言ったら、相手が真っ先に思い浮かべる別の手**（もんでもらう・歩けばいい・買い替える）**が、なぜ足りないかを1〜2文で先に言う**。動画で言い切れない時は、記事への問いにする（「マッサージじゃだめなの？」と思わせたまま商品へ行かない）
- **今している対策を外す時は**、「効かない」だけでなく、「楽になるから、根本から目をそらして、また元に戻ってしまう」という流れで言うと、相手の毎日に重なる
- **変わった後の姿は、ちがう場面を2〜3**。1つだけだと、その場面に当てはまらない人が離れる
- **記事への渡しは、動画に入りきらない訳を短く言ってから問いを渡す**。訳は、相手が「それなら記事で見たい」と納得する具体的な物にする。「図が要るので」だけのぼんやりした訳にしない。例の形：「全部話すと、この動画が10分を超えてしまう」「人によって変わり方がちがうので、何人かの日ごとの記録で見てほしい」「話せたのはここまで」だけで切らない。相手が今思っている疑問を言い当ててから問いを渡す形が伝わりやすい（言い回しは毎回変える。例文をそのまま使わない）

## 4. 日本語
- **相手がしている事は、相手が呼ぶ名前で言う**（「押す」→「マッサージ」、「伸ばす」→「ストレッチ」。2026-10-21 運営者）。動詞でぼかさない
- **一度名前を付けた物は、最後まで同じ名前で呼ぶ**（「痛み物質ブラジキニン」と言ったら、後で「物質」とだけ言わない）
- **体や物が主語の時は、自然な自動詞で言う**（「筋肉は休めない」→「筋肉は休まらない」、「血は流せない」→「血は流れない」の類）
- **（道具）語り方が「あなたに語る」の時、時間や場面を切りかえるなら、「あなたは」で相手を中に入れ、「今、」で今に戻る**（例の形：「一年後の、ある日の◯◯。あなたは、〜」→「今、◯◯なら、この日は、あなたにも必ず来ます」。2026-10-21 運営者）。言い切れる所は「必ず」で言い切る
- **遠回しな言い方（婉曲な言い回し）をしない。1秒で、だれでも分かる文にする**。たとえ・ぼかし・ひねった主語・「〜と言えるでしょう」「〜かもしれません」・気取った言葉を使わず、起きている事をそのまま言う。確かめ：その1文だけを聞いた人が、1秒で「何が、どうなる」を言えるか
- 声に出して、1回聞いて分かる、ふつうの話し言葉。迷ったら、相手が友だちに話す言い方
- 1文ずつ、「何が」「何を」「どこへ」「いつ」が分かる。省いて分からなくなる言葉は省かない
- 同じ事を2回言わない（言い方を変えても同じ事なら1回）
- 並べる物は同じ形にそろえる。「〜ても／〜のに」の前と後ろは、同じ物差しで比べる
- 名詞の無い指す言葉（それ・そこ・これ）だけで物を指さない
- 意味が1つに決まらない動詞（戻る・変わる・効く・届く・抜ける）には、何が・どこへ、を付ける

## 4b. とても分かりやすく書き直す（最後に必ず1周）
決まりどおりに書き終えたら、**決まりのことはいったん忘れて、「画面を見ながら、1回だけ聞く人が、聞きながら全部分かるか」だけを考えて、頭から書き直す。** 見本：`研究/見本/2026-10-21_針マット_分かりやすく書き直した版.md`（読むだけ。写さない）。書き直す時の考え方：
1. **聞く人は、読み返せない。** だから1文に言う事は1つ。「〜して、〜して、〜ので」と重ねた長い文は、出来事ごとに文を分ける
2. **原因の流れは、前の文の結果から次の文を始める。** 「Aになる → このBが◯◯する」「◯◯したBが、Cをつぶす」「Cがつぶれると、Dが届かない」のように、前の文の終わりの言葉が、次の文の頭に来る。どの文も、前の文に「それで、どうなるの？」と聞いた答えになっている
3. **無くても流れが切れない細部は、外す。** 1つずつ消してみて、前後がつながったままなら、その言葉は要らない（細かい作りの名前・正式な名前・細かい場所の言い方など）。正しくても、聞く人の頭に残らない物は入れない
4. **ふだん口で言う言葉に替える。** 書き言葉・気取った言葉（身構える・預ける・しるし・〜にあたる）は、話し言葉（力を入れて踏ん張る・寝るだけ・合図）へ。体の部分は、名前ではなく「どこにあって、何をしている物か」で言う（「◯◯の両側にある、◯◯を支える太い筋肉」の形）
5. **名付けの文を入れない。** 「これが『◯◯』です」「◯◯の正体です」のように、説明の後で名前を付ける文は、聞く人には要らない。名前を言うなら、出てきた所で1回だけ
6. **場面は、短い今の文で。** 「◯◯を止めて、◯◯に手を当てて、ぐっと伸ばす。」のように、相手の動作をそのまま並べる
7. **くり返しは、相手の場面に戻して言う。** 「◯◯をしている間、◯◯の中では、これがずっと繰り返されています」のように、体の中の話を、相手が今している事の上に重ねて終える
8. **書き直したら、声に出して頭から読む。** 一度でも「ん？」と止まった所は、もう一度、1〜4で直す

## 5. 強さ
- 言い切る。困り事の名前・結末を弱めない。但し書きを付けない（技術テスト）
- 誇張してよい。資料に無い数・声・出来事を作った時は「テスト用に決めた値」に書く

## 6. 材料
- **アングル（どの悩みで入るか）は、その商品が解決する一番大きな悩みが既定**。一番大きな悩み＝商品の資料で、相手の数が一番多く、商品が一番まっすぐ解く悩み（F の1位・J の件数1位）。依頼票にアングルがあれば、それ
- それ以外のアングル（2番目の悩み・その結果として起きる事）で書くのは、テストなど意図がある時だけ。その時は、台本の頭に「アングル：◯◯（意図：◯◯のテスト）」と1行書く
- 商品の事実・原因の仕組みは、商品の資料（`商品を読む.md` の順）から取る。資料の仕組みを、別の仕組みに替えない
- 相手は、商品の資料のアングルのページと人物の表（J・K）から決める（`相手を1人に決める.md` 0章の表の形で、資料にある件数を写す）。資料に無い時だけ、原文を集める

## 6b. 迷った時の決め（2026-10-21 第2回の書き手3人が迷った所から）
- **商品の `05_原稿の決まり` の「決まった言い方・締めの文」と、この決まりがぶつかったら、この決まりが先。** 05 の言い方は中身として使い、文の形は毎回変える。05 が「数字は声で読まない」なら、運び「数字から」は選ばない
- **商品の働きは、動画では「原因のどこに、どう働くか」を1〜2文まで。** それで「なぜ直るのか」の詳しい仕組みは記事に残す（`記事と分ける.md`）
- **字数に入りきらない時に外す順**：困り事に近づかない文 → e（今ならまだ戻せる）→ 変わった後の場面を2つに → 記事への問いを2つに。原因の説明（2章）は、困り事に届くまでは削らない
- **相手が責めているのが本人でない時**（生き物・家族・年・道具）、①（あなたのせいではない）は、その責められている物への誤解を解く形で埋める
- **資料に痛みや困り事を起こす物の名前が無い時**は、一般に知られている名前を使ってよい（作った物として「テスト用に決めた値」に書く）。資料が「言ってはいけない」と決めている仕組みは使わず、資料にある一番近い物で言う

## 7. 書いた後の見直し（書き手が自分で。人には見せない）
**先に 4b の書き直しを1周してから**、本文だけを、上から声に出して読み、次の項目を全部「はい」にしてから出す。
1. どの文も1回で分かるか。つながらない文・意味が通らない文は無いか（書き直す。消してよい）
2. 原因の説明の最後が、困り事そのもの（どこが・なぜ）に届いているか
3. 「◯◯が原因」と言った物は、本当にそれが無くなれば困り事が止まる物か
4. 同じ事を2回言っていないか
5. 1章の a〜h が全部あるか
6. フックで本当の原因を言っていないか。フックのデスは目に浮かぶか
7. 決まった文の形（0章の1）が、前の台本と同じ所で出ていないか（台帳と `使った物の記録.md` を見る）
8. 作った値を一覧に書いたか
9. 打ち消している事・疑問として言っている事は、多くの相手が本当に思っている事か（1-2・1-2b）。運びとフックの入り方を台本の頭に書いたか、直前の台本・同じ回の台本と同じでないか（1-3）。フックの問いを次の文で受けたか。デスは相手の暮らしの一番こわい事につながっているか（3章）。アングルは一番大きな悩みか、ちがうなら意図を書いたか（6章）
10. どの文も、遠回しでなく、1秒で「何が、どうなる」が分かるか（4章）。「たまる・残る」の前に、流れ出ない訳を言ったか（2章）
