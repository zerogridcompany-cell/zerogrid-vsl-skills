# 15の心の声 — 動画と記事で、15個を全部埋める

商品の中身は、ここに書かない。元の表（見本の VSL から測った物）は、`_元の表_15の心の声_運営者_20261014.txt`。見本の言い回しは写さない。

## 1. 何か
買う人は、見ている間・読んでいる間に、心の中で次の15の声を言う。15が全部出た人が、買う（言う順は人と台本によって変わる。台本の順は `台本の決まり.md` 1-3 の運びで決める）。
**1本の動画と、その飛び先（記事か商品ページ）を合わせて、15を全部埋める。** 動画だけで15を埋めようとしない（長くなり、押されなくなる）。記事だけでも埋めない（動画が押されない）。

## 2. 受け持ちを決める（台本より先。`記事と分ける.md` の「分け方の表」に書く）
15の1つずつに、**動画・記事（または商品ページ）のどちらが埋めるか**を決める。書くのは次の2つだけ。**穴は作らない。15を全部埋める。**
| 書く言葉 | 意味 |
|---|---|
| **動画** | 動画が、1章の「最低の形」まで言う。記事は、同じ言葉で1行だけ受ける（くり返して説明しない） |
| **記事** | 動画は1文も言わない。記事が「最低の形」まで書く |

**着地ごとの、受け持ちの既定**（寄せ方の1枚が別に決めていれば、寄せ方）
| # | 着地＝記事 | 着地＝商品ページ（直行） |
|---|---|---|
| ①②③ | 動画 | 動画 |
| ④a | 記事 | 動画（1文）か、商品ページ |
| ④b | 記事 | 商品ページ |
| ⑤ | 記事 | 動画（1文） |
| ⑥ | 動画は、する事と、商品が原因のどこにどう働くかを1〜2文まで。それ以上くわしい訳は記事（動画が答えていない時だけ、記事の中心にする。`記事と分ける.md` 2章） | 動画 |
| ⑦ | 記事 | 商品ページ |
| ⑧ | 記事 | 動画（1文）か、商品ページ |
| ⑨ | 動画 | 動画 |
| ⑩⑪⑬ | 記事 | 商品ページ（動画で言うのは、`05` が決めた時だけ） |
| ⑫ | 動画の締めと、記事の締めの両方 | 動画の締め |
| ⑭ | 記事 | 商品ページ |
| ⑮ | 記事の最後 | 動画の締めの前（1文） |

## 3. 埋まったかの確かめ（出す前。動画と記事の両方ができてから）
15行の表を作る：`# ／ 心の声 ／ 受け持ち ／ 埋めた所（動画の何行目・記事の何番目の段） ／ ○・1行で受けた`。
- **○が15そろうまで出さない**
- 動画の受け持ちの声を、記事が同じ厚さでもう一度説明していたら、記事の方を1行に削る
- 記事の受け持ちの声を、動画が言っていたら、動画の方から消す（押す訳が減る）
- 台本だけを先に出す時（記事がまだ無い時）は、動画の受け持ちの行だけを確かめ、記事の行は「記事へ」と書いて渡す

## 4. 材料が無い声
- **技術テストなので、材料が無い声も、書き手が作って埋める。** 人の声・体験談・保証の条件・数も、ふつうに書く。「穴」「本物の声があれば」のような空きを残さない。本文に、断り書き・〔仮〕の印を入れない
- 作った物は、出す時に「テスト用に決めた値」の一覧（`templates/出力の形.md`）に1行ずつ書く（出稿の前に、本物と入れかえるため）。本文はふつうに書く
- 作る時も、相手（人物メモ）と同じ場面・同じ言葉づかいで作る。アングルのページの客の原文の言い回しに寄せる
