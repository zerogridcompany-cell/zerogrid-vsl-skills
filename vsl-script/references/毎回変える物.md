# 毎回変える物（似た台本を出さない）

芯（通る点）と中身の質は同じでも、**聞いた感じが毎回ちがう**台本にする。**ただし、変えるために弱くしない。** 引きつける強さ（書き出しと結末の言葉の強さ）が一番上で、ちがいを出すのはその次。同じ商品では、原因と商品の事実は同じになる。だから、それ以外を全部変える。

## 1. 変える物（7つ。書く前に、台帳の直前の2本と比べて、ちがう物に決める）
| # | 変える物 | 選び方 |
|---|---|---|
| 1 | **型** | `型の選び方.md` |
| 2 | **書き出しの向き** | 中身の質 4。直前の1本と変える |
| 3 | **書き出しの、こわさの種類と着地の言葉** | 強さは下げない。**強いと分かっている種類と言葉は、軸として続けてよい。ただし、直前の3本が同じなら、次は別の種類を混ぜる**（中身の質 4-1b）。どの台本にも、種類ちがいの「書き出しの替え」を2つ付ける |
| 4 | **道具**（下の2） | 1本に2〜3個。直前の1本と、同じ組み合わせにしない |
| 5 | **原因の説明の入り方** | 上から順に言う／結末から逆にたどる／問いに答える形／見る人の動作を追いながら、のどれか |
| 6 | **語り口** | 静かに言い切る／たたみかける／目の前の1人に話しかける／実況する、のどれか。文の長さ・切り方が変わる |
| 7 | **商品の出し方・使った時の言い方** | 商品の事実は同じでも、どこから言うか（形から／使う場面から／要る条件から／使った時の感じから）を変える。前の台本の文を写さない |

## 2. 道具箱（どれも、毎回は使わない。合う時に使う）
| 道具 | 使う時 |
|---|---|
| **たとえ** | 原因の段に1つ。中身の質 6-3 の3つ（なじみ・分かりやすい・的確）を通る物だけ。前の台本と、ちがうたとえにする |
| 見る人の動作の並び | 見る人が毎日している事を2〜3個、短く |
| 問いかけ | 見る人が心の中で言っている問いを、声にする（1本に2回まで。型が問いで運ぶ時は、型の数でよい） |
| 対比 | する前と後／昔と今／している人としていない人／思っている事と本当の事 |
| その場で試させる | 見ている人が、今すぐ自分の体・物・目の前の場所で確かめられる事を1つ（「今、◯◯してみてください」）。確かめた結果が、原因の説明につながる時だけ |
| 数える | 理由・まちがい・段階を、2つか3つに数える |
| 時間を追う | 1日・1週間・1年を、順に追う |
| 大きさの数 | 人数・年数・回数（材料にある数だけ） |
| 言われた言葉 | 見る人が、だれかに言われた一言から入る |
| こわさの後の救い | `引っぱる力.md` の 2 |

道具を使った所は、台帳の「道具」の欄に書く。

## 3. たまに、棚に無い型で書く
- 指定が無い時、**3本に1本は、棚に無い新しい型**で書く（`型/新しい型の作り方.md`）。台帳を見て、直前の2本が棚の型なら、次は新しい型
- 新しい型は、棚の型の言いかえにしない。**運ぶ順・語り手・引っぱる物のうち、2つ以上が、棚のどの型ともちがう**事

## 4. 検品（出す前）
台帳の直前の2本の台本を開いて、今回の台本と並べる。**書き出し・最初の5文・原因の説明・商品の所・最後の姿**を、1つずつ比べる。同じ言い回し・同じ文の形があれば、変える（締めの3文は、同じでよい。書き出しは、中身の質 4-1b の配分で見る）。
- **「前の原稿は読まない」（`商品を読む.md` 4）との順（2026-10-11。逆に読めた）**：書く前は、読まない（材料にしない。重なりは記録で避ける）。**開くのは、書いた後の、この検品の時だけ。** 開くのは、台帳の「台本（置き場所）」の欄の2本
- **台帳が無い・置き場所の台本が開けない時**：「使った物の記録」の項目（書き出し・たとえ・場面・最後の絵）と比べる。記録も無い時は、比べる物が無い事を、報告に書く
- 寄せ方が運びを決める時は、変える物の一覧は寄せ方の物（`SKILL.md` 5b の表）。この検品の比べ方は同じ
