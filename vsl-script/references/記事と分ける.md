# 記事と分ける — 動画と記事が、話す所を分けて、受けわたす（2026-10-12 作成。2026-10-14 書き直し：15の心の声で分ける・引き継ぎ票・押したくなる終わり方）


商品の中身は、ここに書かない。分け方の表と引き継ぎ票は、商品のフォルダに置く。

## 1. いつ使うか
| 依頼票の「着地」 | 台本 |
|---|---|
| 記事 | **この1枚のとおり。** 先に「分け方の表」を決めて、表のとおりに書き、台本の最後に「引き継ぎ票」を付ける |
| 商品ページ（直行） | 2章の表の「商品ページ」の列だけ作る（15の受け持ちを決めるため）。引き継ぎ票は付けない。ほかは今までどおり |

## 2. 分け方の表（台本より先に作る。記事の側と、同じ1枚を使う）
置き場：`<商品名>/06_原稿/分け方/<アングル>_<記事の名前>.md`。**1つのアングル × 1本の記事に、1枚。** 同じ記事へ飛ばす動画は、映像の型が違っても、同じ表を使う。
表は、台本を書く側と、記事を作る側の、両方が読んで決める。先に作った方が書き、後の方は、表を変えたい時は表を直してから作る（片方だけが、だまって表から外れない）。

**表の行は、15の心の声**（`15の心の声.md`）。受け持ちの既定は、その2章。
| # | 心の声 | 受け持ち（動画／記事） | 動画で言う言葉（動画の時。言い切る1文の芯） | 記事で書く事（記事の時。何を材料に、どの段で） |
|---|---|---|---|---|
| ①〜⑮ | | | | |
| **記事の中心（1つ）** | | 動画は「することは1つ」まで | | **くわしく**（作りから） |
| **動画が残す問い（1つ）** | | 動画の最後 | | **記事の題と最初の3文で、答え始める** |

- **記事の中心は、動画が答えていない、相手の一番大きな疑問**。動画は商品が原因のどこにどう働くかを1〜2文で言うので（`台本の決まり.md` 6b）、「なぜ直るのか」を中心にするのは、動画がそれを言わなかった時だけ。ほかは、⑭の一番強い疑い（うちでも使える？・置いていい？・本当に効く？）、⑦⑬の変わり方（何日で、どう変わる）、④aの権威などから選ぶ。同じアングルの2本目の記事からは、7章のとおり中心を変える
- 寄せ方によって、動画で言わない物が増える時（スケルトン寄りは、原因の名前も仕組みも言わない）は、表の下に「◯◯寄りの動画では、◯◯も言わない」と1行書く。表と寄せ方が逆の時は、寄せ方が先

## 3. 動画の側が、必ず守る事
1. **動画の受け持ちの声は、`15の心の声` 1章の「最低の形」まで、必ず言う。** とくに ①（あなたのせいではない）と ②（たよっている物が原因）は、ほのめかしで済ませない（言い方は自由。決まった文の形にしない）
2. **記事の受け持ちの声は、動画で1文も言わない。** 値段・保証・人の声・細かい作り・疑いへの答え・「だれも教えなかった訳」を、少しだけ足さない
3. **動画が言った事は、記事の中心にしない。** 動画は、原因（困り事まで）と、商品が原因のどこにどう働くかを1〜2文まで言う（`台本の決まり.md` 2章・6b）。ただし、原因が何かは、たとえ（`中身の質` 6）で、絵が浮かぶまで言ってよい。**たとえは原因を見せる物。商品の仕組みの説明ではない**
4. **商品を、問いのまま隠さない。** 「ある物」「あの布」と言わずに、名前と、置く・使うと何が起きるか（結果の言葉）は言う
5. **長さ**：記事へ送る時も、短くしない。寄せ方の既定の長さ（ZackDFilms寄りは約3分）。2026-10-14 運営者 の指摘で「直行の6割」を外した
6. 寄せ方・だれの話かを先に指す・相手の言葉、は直行の時と同じ

## 4. 押したくなる終わり方（2026-10-14）
押されるのは、**見る人が、もう半分信じていて、あと1つだけ知りたい事がある時。** 問いを置くだけでは押されない。次の5つを全部やる。
1. **問いは、見る人がその時、心の中で言っている声から取る。** 書き手が聞きたい事ではない。取るのは次のどちらか：
   - ⑥の訳（「でも、なぜ◯◯するだけで、△△が止まるの？」）。ただし動画がそれをもう言った時は、使わない
   - ⑭の一番強い疑い（「でも、うちの◯◯でも、本当に？」）。アングルのページか B の「購入の壁」の一番多い物
2. **問いの前に、希望を最大にする。** 問いのすぐ前の2〜3文は、最後の姿（`中身の質` 9。困り事が無くなった朝・夕方の場面）。希望が一番高い所で、問いを置く
3. **記事で分かる事を、問いの形で2〜3個見せる（4-2）。** 「その訳を、まとめました」で終わらせず、何が分かるかを具体的に言う（例の形：「その訳と、◯◯の時の◯◯を、下の記事にまとめました」）。約束した物は、記事に必ず書く（引き継ぎ票の「約束した事」に書く）。約束は、記事の受け持ちの声から選ぶ
4. **問いと約束は、締めの中で1回ずつ。** 本文の途中で「後で言います」と引っぱらない（動画の中では答えないので、うそになる）
5. **締めは、中身だけ決まっている。順と言い回しは、運び（`台本の決まり.md` 1-3）で毎回決める**（2026-10-21：前の「①問い→②約束→③季節→④売り切れ→⑤リンク」の固定の並びと決まった文が、どの台本の最後も同じ形にしていたので外した）。入れる中身：記事で答える問い（2〜3）・記事へ行く訳・今この時期だけの事（⑫）・行き先。たとえば、問いを冒頭で開けて締めで記事へ渡す／最後の姿の場面の中で問いを言う／⑫を先に言ってから問いで終える、などでよい。前の台本と同じ並び・同じ言い回しにしない
   - 問いを、登場人物のせりふにして終わらせない

## 4-2. 記事への渡し方：「まだ話せていない事」を見せて渡す（2026-10-21：決まった文と並びを外し、中身だけにした）
- 渡す前に、向きを変える一言を入れる（いきなり問いを投げない）。言い回しは毎回、その台本の話に合わせて書く（決まった文を使わない）
- **まだ話せていない事を、問いの形で2〜3個**。選び方：
  - **台本の中で出てきた話の、続き**であること。見る人が、動画を見ながら、もう半分思っている事
  - **記事が受け持つ声**（`15の心の声` 2章の「記事」）のうち、記事の見出しになっている物から取る。並べた問いと、記事の見出しは、同じ言葉にする
  - **動画で答えた事を、問いにしない**（言った事を「記事で」と渡すと、見る人は「もう聞いた」と思う）。問いは、動画で答えていない疑い・変わり方・使える場面の心配から選ぶ。1つは記事の中心にする
- **記事へ行く訳で、相手の不安を増やさない**（「人によってちがう」「店・家ごとに決まりがちがう」「場合による」と言うと、「結局ちがうのか」と思われる。2026-10-21 運営者）。代わりに、相手が置く前・使う前に気になる事を2〜3つ言い当て、記事がどんな記事か（研究や専門家の話をもとにまとめた記事、など）を言って渡してよい
- **記事へ行く訳を、短く言う**（動画に入りきらない訳：図で見ないと分からない・数字を並べないと答えられない、など。`台本の決まり.md` 3b）。**動画では答えない**
- ⑫（今この時期だけの事）は、商品の資料に材料が少ない時も、前の台本と同じ季節の理由をくり返さない。相手の暮らしの、今の時期の別の出来事から、筋の通る訳を作ってよい（作った物は「テスト用に決めた値」）
- 引き継ぎ票の「動画が約束した事」には、並べた問いを全部書く

## 5. 引き継ぎ票（台本の最後に付ける。記事を書く人は、これを先に読む）
動画から記事への、受けわたしの1枚。「ここまでは動画が言った。ここからは記事が言う」を、記事を書く人が迷わない形で書く。
```
引き継ぎ票（動画 → 記事）
- 動画が埋めた声：①②③⑥（することは1つ、まで）⑨⑫。記事は、次の言葉で1行ずつ受ける（同じ言葉を使う。言いかえない）
  - 困り事の言葉：「…」／原因の名前：「…」／商品の呼び名：「…」／することは1つ：「…」
- 動画の最後の問い（記事の題と1文目は、この言葉を使って受ける）：「…」（文字起こしの秒）
- 動画が約束した事（記事に必ず書く。2つまで）：…（秒）／…（秒）
- 残した疑いと重さの候補（記事の移植表の `| 疑い | 重さ | … |` の表になる）：最後の問いと約束した事は重さ1（記事の本文の段で、値段より前に答える。⑭ の FAQ には入れない）。ほかに、答えが「いいえ」なら使えない・買えない疑い「…」も重さ1、迷いが残るだけの疑い「…」は重さ2。答えの材料のありか（指針・決まり・調査）が分かっていれば添える
- 記事が埋める声：④a ④b ⑤ ⑥の訳（中心） ⑦ ⑧ ⑩ ⑪ ⑬ ⑭ ⑮ ⑫
- テスト用に作った物：（声・保証など。記事の側も同じ物を使う）
- 記事で使わない物：動画のたとえ「…」・動画の場面・絵・登場人物
```
- 記事の側は、票の「動画が埋めた声」を、1行で受けてから、記事の受け持ちに入る（`ec-ad-ops/references/article.md` の「15の心の声」）
- 票の「記事が埋める声」の ⑭ に並べるのは、重さ2・3の疑いだけ。重さ1の疑いを ⑭ に入れると、記事が FAQ の1問で済ませる（2026-10-20 立ち仕事マットの記事で「店にマットを置かせてもらえるのか」が FAQ の「店の決まりによります」で終わった）。重さの決め方と答え方は `ec-ad-ops/references/article/型/_買うまでの15の事.md` の「残った疑いの重さと答え方」
- 票と記事がちがう時は、票を直してから記事を書く
- 記事側の作り方は `ec-ad-ops/references/article/05 記事を作る.md` の「VSL 動画の飛び先の記事を一回で作る道」。15の対応と、票から「見終わった人の状態」を取る方法は `ec-ad-ops/references/article/15の対応表.md`

## 6. 記事の側が、守る事（`ec-ad-ops/references/article.md` から、ここを読む）
1. 題と最初の3文は、引き継ぎ票の「動画の最後の問い」に、**その言葉を使って**答え始める（押した人が「これだ」と分かる）
2. 表の「記事の中心」を、一番厚く書く
3. 動画が埋めた声は、票の言葉で1行ずつ受けるだけ（同じ厚さで、もう一度説明しない）
4. 記事が埋める声は、`15の心の声` 1章の「最低の形」まで書く。並びは、その1章の順
5. 動画が約束した事は、必ず書く。見出しに、約束の言葉を入れる
6. 動画の場面・絵・登場人物・たとえは使わない（記事のたとえは、記事で別に考える）

## 7. 次の記事を作る時
同じアングルで、次の記事を作る時は、**中心を別の物に変える**（④a・⑤・⑭ のどれかを中心にしてよい）。表を新しく1枚作る。前の表は消さない。どの記事が何を中心にしたかは、表のファイルの名前で分かるようにする。

## 8. 出す時
台本の下に、引き継ぎ票（5章）と、15の受け持ちの表（`15の心の声` 3章。動画の行だけ確かめた物）を付ける。
