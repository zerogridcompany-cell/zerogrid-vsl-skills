## 5. 映像の側が、台本に求める物（出力に足す欄）
本文は `templates/出力の形.md` のまま。足すのは、次の3つ。

**(a) 印：本文の、行の頭に1つ付ける**（別の一覧にしない。1行に1つ。種類は、この6つだけ。映像の決まりの印と同じ）
| 印 | 何を写すか | 当てる文 |
|---|---|---|
| 【顔】 | 話し手が、カメラに話す（持つ物は、持ったまま） | 言い切り・橋・原因の1文・商品の名前・締めの前の1文・締め③ |
| 【物】 | 実物の寄り（話し手の手元・台の上） | 物の名前・「これ」・作りを言う文・締め② |
| 【実演】 | 手が、本物を動かす・並べる・たらす・置く | やって見せる文・入っている物を並べる文・使い方 |
| 【たとえ】 | 身近な物を、机に置いて、やって見せる | たとえの入り口から、対を言う文まで |
| 【中】 | **目に見えない所で起きている事**（体の中・物の中・人に見えない仕組み）の絵 | 仕組み。3〜4歩を、1歩ずつ |
| 【暮らし】 | 相手の毎日の場面・物の寄り（人の顔は写さない） | 相手がしている事・困り事の場面・最後の姿・締め① |

1文目の印は、【暮らし】（相手の家の場面）か【物】（話し手が、その物を手に持つ時）。

**(b) 持つ物・実演の表**（本文の下。映像の担当が、先に絵を作る）
- `持つ物：①◯◯（1文目〜）／②◯◯（「これを見てください」の文〜）／③商品（名前の文〜締め）`。3〜5つまで。本物があって、片手で持てて、名前を言える物だけ。資料に無い道具・実在の会社の物・読める文字のある物は書かない
- 表の列：`#｜実演（何を、どうする）｜どの文｜使う物｜もとの事実（資料の所）｜撮る前`
- **「撮る前」の列**：資料に、その通りの実演が書いていない時は、「実物で確かめてから撮る」と書く（書いてある時は「—」）。本文には、印を書かない。`出力の形` の「確かめてほしい所を並べない」は、運営者 への質問を並べない、という決まり。この列は、撮る人への作業の印なので、ぶつからない

**(c) 顔の数え**（1行）：`顔：◯回・合わせて◯字（全体の◯％）・一番長い間◯字`。3章の「顔」の線から外れたら、直してから出す。

台本に書かない物：カメラ・光・字幕・効果音の指示（映像の決まりの仕事）。断り書きの文（出すかどうかは 運営者 が決める）。

## 6. 型の棚
**棚（読む順 5）は、選ばない。** 台帳には「権威実写寄り・実物で見せる」と書く。「毎回変える物」は、入口・相手・1文目の物・たとえの物・実演の順・最後の姿、で変える。話し手が2人以上になる型・形を借りる型を指定された時は、ZackDFilms寄りで書き、報告に書く。

## 7. 書いた後の確かめ
1. **作り物**：名前・肩書き・役・年数・人数・資格・「研究では」・他人のせりふ・【人々】が、1つも無いか。数字は、資料にある物だけか
2. **書き出し**：1文目は、30字までで、だれの話かを、その人の場面・している事で指しているか。2文目は、中で起きている事の言い切りか。3行目までに【顔】があるか
3. **実物**：実演が3つ以上あり、「これを見てください」の段が、原因と商品の両方にあるか。たとえは1つで、対を言っているか。【中】の段の前に、実演かたとえがあるか。「これ」「ここ」の全部に、持つ物があるか
4. **顔**：全体の2割まで（締めも数えて）・1回20字まで（締め③は別）・間は100字まで・2行続いていないか。商品の名前を初めて言う文が【顔】か
5. **締め**：前の1文は、1つで【顔】か。3文は、決まった文のまま、暮らし → 物 → 顔か
6. **形**：全部の行の頭に、6つの印のどれかが1つあるか。30字をこえる文・「〜と言われています」が無いか。(b) の表の全部の実演に、もとの事実か、「実物で確かめてから撮る」があるか
