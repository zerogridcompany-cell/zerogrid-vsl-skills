# ZackDFilms寄り（第4版・2026-10-21 作り直し・同日 運営者 の OK で本物へ）

（前の第3.5版は `_外した_20261021/寄せ方/ZackDFilms寄り_第3.5版.md`。決まりが積み重なり、決まった文の形と段の数の決まりが、台本を同じ型にしていたので作り直した）

伝える事と質は `references/台本の決まり.md`。この1枚は、それを **Zack D. Films の伝え方** で運ぶ時に、何が変わるかだけを書く。

## 1. どんな台本か
Zack D. の書き手は、説明を書かない。**1文＝1カットの短い映画**を、見る人の頭の中に順番に映す。次のカットを見ないと今のカットの意味が分からない順に並べるので、気づいたら最後まで見ている。声は淡々としていて、驚きの言葉（すごい・驚きの・なんと）を言わない。驚くのは見る人。

## 2. 先に読む物
- `寄せ方/ZackD/書き手の頭.md`（Zack D. の109本から、書き手が何を考えて書くか。必ず全部）
- `寄せ方/ZackD/フォーマットの家族.md`（運びの手札。どの家族が何本・何回見られたか）
- `寄せ方/ZackD/俺らへの落とし込み.md`（家族ごとに、伝える事と商品がどこに乗るかの例。**例の文は写さない**）

## 3. 運び（既定と、変え方）
**既定の運び**：

フック → 場面（相手が思っている事が出る） → 外れている → 原因（`台本の決まり` 2章。困り事まで） → 放っておいた先 → 今の段階 → する事と商品・うちだけの所 → 変わった後の姿 → 記事への渡しと締め

- **戻らない。** 原因を言い終えたら原因に戻らない。商品を出したら原因に戻らない
- **運びは毎回変えてよい。** `フォーマットの家族.md` の家族（出来事の途中から・もし〜なら・〜するとどうなる・たいていの人は〜する、でも・犬や体の目線・時間の目盛り など）で、既定の順を組みかえてよい。どの家族でも、`台本の決まり` 1章の a〜h は全部入れる。前の台本（台帳）と同じ家族・同じ順が続いたら、次は変える
- 既定の順を変えた時は、台本の頭に「運び：◯◯の家族（順：…）」と1行書く

## 4. Zack D. の道具（使うかは書き手が決める）
| 道具 | 中身 |
|---|---|
| 結果を先に、訳は後 | 起きた事を先に見せ、「実は」の後で訳を言う |
| 「でも」で1回ひっくり返す | 思いこみを外す時・一段悪くなる時。前より強い絵にする |
| はしご | 1段ごとに大きく・ひどく。下がる段を作らない |
| あなたを場面に置く | 「もし、あなたが〜」で、見る人の体を場面に入れる |
| 中の目 | 体・物・生き物の目の高さで、中で起きている事を見せる（原因の説明に合う） |
| 数をさわれる物に | 数字は、何と同じかで言う。時間は「何分・何時間・何年」と目盛りで |
| 五感を1か所だけ濃く | 一番いやな所を、手ざわり・温度・音で1か所だけ |
| 最後の1文で、最初の絵に戻る | 変わった後の姿で、フックや場面の絵に戻る |

## 5. 段階で変わる所
- **①（困っているが問題だと思っていない）**：フックは意外な事実とデス。b は「こんなものだ、ではない」
- **②（困っていて、何かのせいにしている）**：既定のまま
- **③（対策を試している）**：b は今の対策を名指して「それでは止まらない」。原因は「今の対策が届いていない所」。放っておいた先は「今の対策を続けた先」
- **④**：この寄せ方の外

## 6. 長さ
- 目安 900〜1,100字（声に出す字だけ。約7字/秒で2分10秒〜2分40秒）。依頼票に長さがあれば、それ
- 1文は30〜40字まで。動作は「、」で2〜3つつないでよい
- 長くなった時は、困り事に近づかない文から削る。原因の説明は、困り事に届くまでは削らない

## 7. 映像の側が台本に求める物
- どの文も、3Dの1カット（2〜4秒）の絵になる。気持ちだけ・理屈だけの文を2つ続けない
- 原因の説明は、「どの物の、どの目の高さで見せるか」が分かる言葉で書く（映像の側が絵コンテにする）

## 8. この寄せ方での見直し（`台本の決まり` 7章に足す2つ）
1. 声に出して読み、淡々とした1本の映画として、次のカットを見たくなる順になっているか
2. 驚きの言葉・あおりの言葉（すごい・衝撃・なんと・ぜひ・今だけ）が無いか
