# 寄せ方 — 映像の型に、台本の伝え方を寄せる

**基盤は変えない**（認知段階の芯・商品を読む・相手を1人に決める・中身の質・引っぱる力）。寄せ方の1枚には、**基盤との違いだけ**を書く。商品の中身は書かない（SKILL.md の大もとの決まり）。

## 寄せ方の1枚に書く事（新しい型を足す時も、この見出しで）
1. **どんな台本か**（3行。見本の動画を測った結果から）
2. **基盤のまま守る事**（商品を読む・相手を1人に決める・だれの話かを先に指す・原因の1文・商品が原因に何をするか・締めの3文、は必ず入る。段階の芯の順番と厚さを、どこまで守るかは、寄せ方ごとに書く）
3. **基盤から変える事**（表：何を／基盤では／この寄せ方では）— 書き出しの形／運び方（順番・区切り）／文の長さと調子／話し手／商品の出し方・締め
4. **認知段階ごとの当て方**（①〜④で、どこが変わるか。商品が出る位置）
5. **映像の側が、台本に求める物**（画面の帯・区切りの言葉・せりふの形など。台本の出力に、何を一緒に書くか）
6. **相性の良い型・合わない型**（`型/` の棚のうち）
7. **書いた後の確かめ**（この寄せ方になっているか、を3〜5問）
8. **見本の動画の運び**（測った表。**言い回しは写さない。運び方だけ見る**）

## 寄せ方と、型の棚
- 寄せ方が、運び（順番・区切り）まで決めている時（スケルトン・クレイ物語・権威実写）は、**型の棚（読む順 5）は選ばない**。ZackDFilms 寄りの時だけ、棚から選ぶ
- ZackD POV 寄りも、運びを寄せ方が決める（型の棚は選ばない。2026-10-12 足した）
- 運営者 の直しは、寄せ方の1枚の本文に入れこむ（「0章」として上に足さない。足すと、下の古い文と逆になり、読む人ごとに取り方が変わった＝2026-10-11）。直した時は、その1枚の中に、逆を言う文が残っていないかを見る

## 新しい型が来た時
見本の動画を測る（声の書き起こし・文ごとの秒・区切り・画面の文字）→ 上の見出しで1枚書く → この表に1行足す。基盤のファイルは書きかえない。
