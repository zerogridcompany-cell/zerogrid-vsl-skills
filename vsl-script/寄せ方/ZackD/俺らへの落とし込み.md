# 俺らへの落とし込み — Zack D. の家族で、15の心の声を運ぶ（2026-10-15）

前提：`書き手の頭.md`・`フォーマットの家族.md`。15の心の声は `vsl-script/references/15の心の声.md`。相手は段階②（何か別の物のせいにしている人）。見本の商品は、新ワンドライ（責めている物＝**叱った自分**・**シーツ**）と、新針マット（責めている物＝**湿布**・**歳**・**検査の「異常なし」**）。商品の事実は 新ワンドライ/` と `新針マット/` の 01・05 だけから取った。

# 0. 先に決めておく事（どの家族でも同じ）

**長さの差をどう埋めるか。** Zack D. は1本35秒・約250字。俺らは1〜3分（3分なら約1,100〜1,300字）。1本の Zack D. を引きのばすと、ゆるむ。やり方は、**Zack D. の1本ぶん（30〜40秒・1つの問い）を、3〜5つ、くさりのようにつなぐ。** 1つの問いを閉じる文の中で、次の問いを開ける（「でも、それで終わりではありませんでした」ではなく、閉じた答えの中に次の「え？」を入れる）。15の心の声は、このくさりの「つなぎ目」に置くと、段を足さずに入る。

**「これはあなたの話」への切りかえ。** Zack D. は、見る人を最初から体に入れる（If you…）か、最後の1文で今につなぐ（…we have today）。広告では、**切りかえを2回** にする。1回目は書き出し（見る人の場面）、2回目は商品の直前（「だから、あなたの犬は」）。真ん中は、犬・血管・床の目の高さで見せて、見る人に「自分で気づかせる」。

**①（あなたのせいではない）は、Zack D. の「You see,（実はね）」の位置に置くと、一番自然に入る。** 実はね、の後に来るのは、見る人の知らなかった本当の訳。そこで「あなたの叱り方のせいではない。犬の鼻がそう出来ている」と言えば、説明ではなく種明かしになる。

**広告っぽくなって離れられる所（全部の家族に共通）**
1. 商品の名前が、問いが閉じる前に出る（まだ「なんで？」が空いているのに、答えより先に商品が来る）
2. 商品の段で、急に文が長くなり、絵が消える（素材・層・回数の並べ書き）
3. 締めで、急に声の温度が上がる（「今だけ」「ぜひ」）。Zack D. の声は最後まで平ら
4. 「多くの方が悩んでいます」のような、だれの体でもない文

# 1. A 出来事の途中から（今の Zack D. の主力）

**形**：一番いやな瞬間の手の動き → まわりの反応 → 「実はね」で訳 → But で一段悪く → 解決 → 最初の絵に戻る。

**新ワンドライ（相手＝叱ってしまう人）**
- 1行目：「朝6時、彼女は床の水たまりを見て、『また！』と声を上げた。犬は耳をふせて、ソファの裏へ逃げた。」（③の予告：だれの話か → やばい）
- 「その夜、ふとんの中で、彼女は朝の自分の声を思い出していた。私の教え方が悪いのかな。」（②：責めているのは自分）→ 「実はね、犬は、トイレの場所を、人の声では決めていません。鼻で決めています。」（①＋原因の名前「においの目印」）→ 犬の鼻の目線で、白いシーツ＝何も書いてない紙、拭いた床＝一番濃い目印（たとえ1つ）
- But：「叱るほど、犬が覚えたのは『人の前でしたら、こわい』。だから次は、隠れてする。」（③：放っておいた先＝家の中じゅうがトイレになる）
- 解決：「することは1つ。目印を、床から、トイレに移す事。」（⑥）→ ワンドライ（⑨）→ 最初の絵に戻る「朝6時、床はかわいている。犬は、パッドの上で、しっぽをふっている。」
- **商品が出る所**：全体の6〜7割の所。「実はね」で原因が閉じ、But で悪くなった後
- **あなたへの切りかえ**：2文目の「私の教え方が悪いのかな」で、見る人が自分の声だと気づく。3人称（彼女）のまま進めて、商品の直前で「あなたの犬も、たぶん今夜、同じ床を選びます」と2人称に切りかえる
- **危ない所**：「彼女」の話が作り話に聞こえる。Zack D. の出来事は実話なので強い。俺らは**相手の原文（「すぐに後悔します」「飼い主失格だし」）の言葉をそのまま、彼女のせりふにする**と、作り話に見えにくい

**新針マット（相手＝湿布を貼っている人）**
- 1行目：「朝、布団から出て、床に足をついた瞬間、彼は腰を押さえて、その場にしゃがみこんだ。腰には、ゆうべ貼った湿布が、まだ2枚。」
- ② 湿布を名前で →「実はね、湿布が冷やしているのは皮ふのすぐ下。固まっているのは、その奥の筋肉です。」① 「あなたの歳のせいでも、貼り方のせいでもありません。」→ 原因「筋肉の酸欠」とたとえ1つ
- But：「湿布が効かなくなると、2枚重ねる。でも奥の血管は、つぶれたまま。」③ → ⑥「することは1つ。固まった筋肉を、広い面で押して、放す事。」→ 針マット ⑨ → 最後「朝、湿布をはがさずに済んだ腰で、すっと立ち上がる。」
- **危ない所**：湿布をけなしすぎると、湿布を貼っている見る人が自分を責められたと感じる。湿布は「悪者」ではなく「届いていない物」として言う

# 2. B もし〜なら（What If）

**形**：ありえない条件を1つ → まず起きる事 → 数で必要な物 → はしごで一段ずつ → 一番上で止める。

**新ワンドライ**
- 題：「もし、あなたの鼻が、犬の鼻だったら？」
- 1行目：「もし、あなたの鼻が、犬と同じだけにおいを感じたら、人の十数倍のにおいの受け口で、あなたのリビングは、においの地図に変わります。」（犬の受け口1億以上・人600万の事実を、そのまま比べる）
- はしご：①白いシーツ＝何も書いてない ②きのう拭いた床＝まだ光っている ③先週の床＝もっと濃い ④ソファの裏＝いちばん濃い。「あなたなら、どこでしますか？」→ ①「あなたの犬が床でするのは、しつけのせいではない。鼻が正しく働いているだけ」②「シーツを大きくしても、地図は変わらない」
- 商品：はしごの一番上（ソファの裏が一番濃い）で③を言った後、「では、この地図の、いちばん光る所に、トイレを置けたら？」→ フェロモンを生地に入れたワンドライ（⑥⑨）。**同じ「もし」で、商品を出す**ので、ひと続きに聞こえる
- **あなたへの切りかえ**：題からもう「あなたの鼻」。最初から2人称
- **危ない所**：ありえない条件の話を長くしすぎると、自分の困り事から離れる。はしごは3〜4段で、毎段「あなたの床」の場所（ドアの前・ソファ・シーツの横）を使う

**新針マット**
- 題：「もし、6,000本の針の上に、10分寝たら？」（依頼主の「針を刺すとどうなる？」を、商品そのものの問いにした形。突起の数は実物で確かめてから入れる。資料には実物の数が無い）
- 1行目：「もし、6,000本の針の上に、あおむけで寝転んだら、背中に穴が開く、と思うでしょう。でも、体の重さは、6,000の点に分かれます。1本あたりは、指で押すくらいの力しかありません。」（F の思いこみ崩しを1行目に入れる）
- はしご：0分 チクチク → 3分 痛みが消える → 5分 背中がじんわり温かい → 10分 …（ここで「なぜ温かい？」を開ける）→ 原因（筋肉の酸欠）を「実はね」で → ②「湿布は、この奥まで届かない」① 「歳のせいではない」→ ③
- 商品：題の時点でもう出ている。**商品が問いの主役なので、広告に見えない**。名前（針マット）は、はしごの後
- **危ない所**：「針」がこわすぎると、最初の3秒で離れる人がいる。1行目の2文目で、すぐ「1本あたりは指で押すくらい」と安心させる（Zack D. の「歯が無いので、たぶん傷つかない」と同じ動き）

# 3. C 〜するとどうなる（時間で進む）

**形**：始まりの状態 → 数時間 → 数週間 → 数年。目盛りごとに一段こわれる → 実際にそうなった人。

**新ワンドライ**
- 題：「床でしたおしっこを、毎日拭くだけにしたら、どうなる？」
- 目盛り：その日（人の鼻では消えた）→ 1週間（犬はまた同じ場所を選ぶ。目印が濃くなる）→ 何か月（継ぎ目の奥へしみる。掃除で取れない）→ 何年（年とともにくせが強くなり、床が、その犬のトイレになる）。日数の数字は出どころが無いので、言わない（「何か月か」「何年か」まで）
- ③（放っておいた先）は、**この家族そのもの**。②は1つ目の目盛り（「拭けば消える、と思っていた」）、①は2つ目の目盛りの後（「あなたの拭き方が悪いのではない」）
- 商品：最後の目盛りの後で、時間を巻き戻す。「でも、今日から、トイレそのものに目印を置けば、この時計は止まる。」→ ⑥⑨ → 同じ目盛りを逆向きに（その夜：パッドへ／1週間：床を拭かない朝）
- **危ない所**：こわい目盛りが続くと、見る人が責められていると感じる。2つ目の目盛りの直後に①を入れて、見る人を味方側に置く

**新針マット**
- 題：「腰の痛みを、湿布だけでしのぎ続けたら、どうなる？」
- 目盛り：今夜（貼れば朝は楽）→ 何か月（効かなくなって2枚重ねる＝原文「効かなくなってきたな」）→ 何年（かばう歩き方で、反対側まで固まる）→ 筋肉が細くなる
- ②は1つ目、①（歳のせいではない）は2つ目の後、原因は3つ目の手前で「実はね」
- 商品：巻き戻し。「10分、寝転ぶだけで、この時計を毎晩0に戻せる。」→ 0分・5分・10分の目盛り（同じ時計の絵を使い回す）
- **危ない所**：「何年」の先を強く言いすぎると、上限の線（05の決まり）を越える。「筋肉が死ぬ」は前の承認台本の言い方の範囲で

# 4. D 仕組みの手順（How It Works・体の中）

**形**：手順の1手目（こわい・痛い・もったいない動作）→ Then で4〜6手 → 完成形。チャンネル最多（縫った傷・とげ・注射のあざ）の家族。

**新ワンドライ**
- 題：「犬が、トイレの場所を決めるまで」
- 手順：鼻を床に近づける → 上あごの上の器官（鋤鼻器）で仲間の合図を受け取る → いちばん濃い所を選ぶ → 足の裏で、やわらかく吸う所を確かめる → くるっと回る → する。この6手を、犬の体の中の目線で（`I_仕組みの細部.md` の9歩から）
- 15の声：手順の途中で、「ここで、白いシーツは何も合図を出していない」（②）、「あなたが教え忘れたのではない。この手順に、声の出番が無い」（①）
- 商品：手順をもう一度くり返す。今度は、鼻を近づけた先にワンドライがある（⑨）。**同じ6手を2回見せて、2回目だけ結末が変わる**
- **危ない所**：仕組みの言葉が増えると、学びの動画になって、自分の困り事から離れる。1手＝1カット＝1文を守り、専門の名前は1つだけ

**新針マット**
- 題：「固まった腰の奥で、毎晩起きている事」
- 手順：同じ姿勢 → 奥の筋肉が固まる → 中の血管をしめる → 血が止まる → 酸素が来ない → 痛みを出す → 痛いからまた固まる（輪）。これが**縫った傷の動画と同じ「体の中を順に見せる」形**
- 商品の手順：寝転ぶ → 体の重さが点に分かれる → 筋肉が押されて、放される → 血管が開く → 血が流れこむ → 温かい
- **危ない所**：体の中の話で終わり、見る人の朝に戻らない。最初と最後の1文は、見る人の朝の動作にする

# 5. E やり方・助かり方（みんながする事を否定 → 本当のやり方）

**形**：まずい状況 → 「たいていの人は〜する」→ 「でも、それは逆効果」→ 「そうではなく」→ 手順 → 最後の手。**段階②に一番ぴったりの家族。** 「たいていの人は〜する」が、そのまま②（たよっている物）になる。

**新ワンドライ**
- 題：「犬がシーツの横でした時、やってはいけない事」
- 1行目：「犬がシーツの横でしたら、たいていの人は、すぐ叱って、すぐ拭いて、シーツを大きいのに替えます。」（② 3つを1文で）
- 「でも、その3つとも、次の失敗を呼びます。」→ 1つずつ短く：叱る＝隠れてするようになる／拭く＝人の鼻だけ消える／大きくする＝目印が無いのは同じ（①「あなたが悪いのではない。順番が逆なだけ」）
- 「そうではなく」：目印をトイレに置く → ワンドライ（⑥⑨）→ 最後の手「最初の1週間は、場所を動かさない」（商品の使い方の事実）
- **あなたへの切りかえ**：1行目からもう「あなた」の行動。最初から2人称
- **危ない所**：「やってはいけない」が、見る人への説教に聞こえる。Zack D. は「most people（みんな）」と言って、見る人を一人にしない。**「あなたは間違っている」ではなく「みんな、こうする」と言う**

**新針マット**
- 題：「朝、腰が伸びない時に、たいていの人がする3つの間違い」
- 「たいていの人は、湿布を貼る、もむ、様子を見る。でも、どれも、奥の固まりに届きません。」→ 1つずつ → 「そうではなく、広い面で、奥まで押して、放す。毎日。」→ 針マット → 最後の手「最初の3分のチクチクは、そのまま。5分で温かくなる」
- **危ない所**：手順の家族は30秒が強い。3分にする時は、間違いを1つずつ「場面→But→実はね」の小さな1本にして、3回くり返す

# 6. F 思いこみ崩し（〜と思うでしょ？ でも）

**形**：みんなの思いこみをそのまま言う → But → 実はね（本当の仕組み）→ 身近な物で1文の答え。②（たよっている物が原因）が、そのまま思いこみになる。

**新ワンドライ**
- 題：「シーツを大きくすれば、はみ出さない？」
- 「シーツの横でするなら、大きいシーツにすればいい、と思うでしょう。でも、大きいシーツにした家でも、犬はやっぱり、その端でします。」（相手の原文「大きいサイズのトイレを買っても結局はみ出してる」）→ 実はね（目印）→ 答え「犬が探しているのは広さではなく、においの目印です。」
- 商品：答えの後に、「では、目印が入っている布があったら？」→ ワンドライ。ここでは L の広さ（約33%）は**後から足す良さ**で、主役はにおい（05の決まりの順）
- **危ない所**：30秒で答えが出るので、後の2分が説明になりやすい。答えの後に、もう1つ思いこみを崩す（「叱らなければ覚える？」）を続けて、くさりにする

**新針マット**
- 題：「検査で『異常なし』なら、腰は悪くない？」
- 「レントゲンもMRIも異常なし。なら、腰は悪くない、と思うでしょう。でも、写真に写るのは骨です。固まっている筋肉は、写りません。」（原文「レントゲン、CT、MRI…異常はなく」）→ ① 「気のせいでも、歳でもありません」→ 原因 → 商品
- **危ない所**：医者を悪者にしない。「写る物と写らない物がある」という事実で言う

# 7. G 想像して・視点（犬の目・体の目）

**形**：「あなたが〇〇だとします」→ 今の時制の短い文 → 主人公の勘ちがい（見る人は答えを知っている）→ くり返すたび強くなる → 主人公の思いこみのまま閉じる。Zack D. の「犬の目で見た郵便屋」（1,400万）がそのまま使える。

**新ワンドライ（一番の推し）**
- 題：「犬の目で見た、トイレの失敗」
- 「あなたが、この家の犬だとします。朝、鼻を床に近づける。きのうの場所が、まだにおう。ここだ、とあなたは思う。した。すると、大きな声が来た。耳がふせる。なぜ怒られたのか、分からない。分かったのは、『人の前でするのは、こわい』という事だけ。次の朝、あなたは、ソファの裏へ行く。」
- 15の声：見る人（飼い主）は、犬の頭の中を見て、自分で①に気づく（「私の叱り方のせいじゃなかった。犬は、そもそも分かっていなかった」）。書き手が①を言う前に、見る人の中で①が起きる。その後で書き手が1文で言い切る（最低の形を満たすため）
- 商品：犬の目のまま出す。「ある朝、鼻の先に、今まで無かったにおいがある。床より、ずっと濃い。『ここがトイレ』と書いてある。あなたは、そこへ行く。だれにも、怒られない。」→ その後で、人の目に戻して「それが、ワンドライ」（⑨）
- **あなたへの切りかえ**：最後の1文で犬の目から飼い主の目へ。「あなたの犬も、ずっと、そう思っていた。」
- **危ない所**：犬の気持ちをかわいそうに描きすぎると、見る人が罪悪感で動画を閉じる。①を早めに入れる（犬が分かっていないのは、だれのせいでもない）

**新針マット**
- 題：「あなたの腰の奥の、1本の血管の目で見ると」
- 「あなたが、腰の奥の、細い1本の血管だとします。朝から8時間、まわりの筋肉が、ぎゅっと固まって、あなたをつまんでいる。血が通れない。夜、上に湿布が貼られる。冷たい。でも、つままれたまま。」（②を、血管の目で）→ 寝転ぶと、まわりが押されて、放される。一晩ぶりに、血が流れこむ
- **危ない所**：体の中のPOVは、絵（映像）の出来に強くよる。3Dの体の中のカットが作れる時だけ

# 8. H 架空の発明品（Patent Pending）の形を、本物の商品で

**形**：困った瞬間 ＋ 道具がする事 → 仕組み3〜4手 → 有料版でもう一段 → But で裏目 → 主語がひっくり返る最後。依頼主がくれたリール1本目がこれ。

**大事な判断**：本物の商品に、笑いの「裏目」（イスから吹き飛ぶ）は使えない（商品を悪く見せる）。使うのは**前半の「困った瞬間 → 仕組み3手 → 一段上の結果」と、最後の主語のひっくり返し** だけ。裏目の役は、**比べる相手（シーツ・湿布）に回す**。

**新ワンドライ**
- 1行目：「犬がトイレの前で迷ったら、布の芯から、犬の鼻にだけ届く合図が出る。」（仕組みの1手目を、困った瞬間とつなげて）→ 2手目（鼻が受け取る）→ 3手目（犬が自分から乗る）→ 一段上（表面はすぐ乾き、床へ1滴も通さない）→ さらに一段（洗っても、合図は落ちない）
- 裏目はシーツへ：「白いシーツは、替えるたびに、合図ごと、ごみ箱へ捨てられる。」
- 最後の1文：「あなたが犬にトイレを教えなくていい。トイレが、犬に教える。」
- 15の声：この形は商品が主役なので、②③が弱くなりやすい。**1行目の前に、0.5段（困った瞬間の5秒）を足す**と②が入る：「シーツを大きいのに替えて、3日目。また横でした。」
- **危ない所**：一番広告に見える家族。Zack D. のシリーズも中央値1,000万で、チャンネル並み。**入口には使わず、2本目以降（記事から戻った人・段階③の人）に回す**のが安全

**新針マット**
- 1行目：「床に敷いて、寝転ぶ。それだけで、体の重さが、数千の点に分かれて、腰から背中を一度に押す。」→ 押されて放す → 血管が開く → 一段上（手を使わないので毎晩できる）
- 裏目は湿布とマッサージ器へ：「湿布は皮ふの上で止まる。マッサージ器は、持つ腕が先に疲れる。」
- 最後：「あなたが腰をもむのではない。あなたの体の重さが、あなたの腰をもむ。」

# 9. I 時間の長さ ＋ 新しく作る「日めくり（1日目・3日目・14日目）」

Zack D. は「For 26 years」と長い時間を1文で飛ばし、終わりを「たった1つの動作」で見せる。日めくりは Zack D. には無い（起こした中に0本）が、この「時間の飛ばし方」と、C の「目盛り」を合わせると作れる。

**新ワンドライ**
- 前半（I の形）：「シーツを替え続けて3年。床を拭いた回数は、1,000回をこえた。」（毎日1回なら約1,100回の計算。数は計算で出せる物だけ）→ その間に試した物（大きいシーツ・スプレー・教室）を1文で並べる（②）→ 「それが、たった1枚の布を敷いた夜に、止まった。」
- 後半（日めくり）：1日目の夜（犬が鼻を近づけて、乗った）／3日目の朝（床がかわいている）／2週間目（叱る言葉を、もう2週間言っていない）＝④b・⑦の「何日目に何が変わったか」を、そのまま場面で埋められる
- **危ない所**：日めくりは「使った人の体験談」なので、テスト用に作った声は一覧に書く（15の心の声 4章）。「1日目に必ず」は上限を越える（05：「初日から◯%」は言わない）。「ある家では」と一人の話にする

**新針マット**
- 前半：「湿布を貼り続けて9年。」（腰痛歴の平均9.9年。B の数字）→ 1枚の針マット
- 後半：1日目（チクチク → 5分で温かい）／7日目（朝、湿布を貼るのを忘れていた）／30日目（駅の階段で、手すりを使わなかった）

# 10. J 作り話・K 教訓（使い方の注意だけ）

- **J 作り話**：チャンネルで一番強い家族（中央値2,150万）で、長くても見られる（108秒・281語でも7,700万）
- **K 教訓**：「小さな場面 → 実はね → あなたへ」。最後の締め（⑮：動かない方がこわい）にだけ借りる。「新しい車を買うと、同じ車が急に目につく。床を拭く毎朝も、同じです。慣れると、見えなくなる。」

# 12. 日本語の題名・1行目の型の案

Zack D. の題名の形を、日本語の広告の1行目にした物。〔〕は入れかえる所。

**問い（もし・どうなる）**
1. 「もし、〔6,000本の針の上に10分寝〕たら、〔背中〕の中で何が起きる？」
2. 「〔床のおしっこを拭くだけ〕を、〔1年〕続けたら、どうなる？」
3. 「もし、あなたの鼻が、犬の鼻だったら、〔このリビング〕はこう見える。」
4. 「〔湿布を貼り続けた腰〕の奥を、開いて見ると。」

**思いこみ崩し**
5. 「〔シーツを大きく〕すれば〔はみ出さない〕、と思っていませんか。」
6. 「〔検査で異常なし〕なら、〔腰〕は悪くない？」
7. 「〔叱らなければ〕覚える、は半分まちがいです。」

**みんながする事（E）**
8. 「〔犬がシーツの横でした〕時、たいていの人がする〔3つ〕の事。全部、逆効果です。」
9. 「〔朝、腰が伸びない〕時、まずしてはいけない事。」

**出来事の途中から（A）**
10. 「〔朝6時、くつ下のまま、ぬれた床をふんだ〕。」（動作だけで始める）
11. 「〔彼女は、新しいシーツを敷いたその夜に〕、〔また床を拭いていた〕。」
12. 「〔9年間、毎晩湿布を貼っていた男〕が、〔ある夜、湿布を貼り忘れた〕。」

**時間・日めくり（I）**
13. 「〔床を拭いた回数、3年で1,000回〕。それが〔1枚の布〕で止まった。」
14. 「〔針マット〕を敷いて、1日目、3日目、30日目。」

**視点（G）**
15. 「犬の目で見た、〔トイレの失敗〕。」
16. 「あなたが、〔腰の奥の血管〕だとします。」

**仕組み（D）**
17. 「犬が、トイレの場所を決めるまでの〔6〕つの手順。」
18. 「〔寝転んで10分〕。背中の奥で、順番に起きている事。」



# 13. 一番いい3つ（推し）

1. **G 視点（犬の目・体の中の目）× 新ワンドライ**。①（あなたのせいではない）を、書き手が言う前に、見る人が自分で感じる。叱ってしまう人の罪悪感を、説明ではなく、犬の頭の中を見せる事でほどく。Zack D. の「犬の目で見た郵便屋」がほぼそのまま使え、商品も犬の目のまま「床より濃い、ここがトイレの印」として出せるので、広告に見えにくい
2. **B／C 「もし〜したら、どうなる？」で、商品そのものを問いにする × 新針マット**。依頼主の言う「針を刺すとどうなる？」がそのまま題になる。商品が問いの主役なので、名前より先に商品の絵が出ても、広告ではなく「答えを見たい物」になる。0分・3分・5分・10分の目盛りで、はしごと時間の両方が使える
3. **E 「たいていの人は〜する。でも、それは逆効果。そうではなく」**。段階②（別の物のせいにしている人）の、②・①・⑥ が、この家族の段の並びにそのまま重なる。チャンネルでも上位（車のトランク1億500万・ウォータースライダー1億900万）。2つの商品のどちらにも使えて、3分にする時は、間違いを1つずつ小さな1本にしてくさりにできる

土台として、どの家族を選んでも、**1行目は A（出来事の途中の、一番いやな瞬間の動作）から入る** のを既定にすると、今の台本の「書き出し2文 → 場面」から、いちばん少ない変更で寄せられる。
