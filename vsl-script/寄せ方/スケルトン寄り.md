## 1. どんな台本か
- 最初に「…すると、どうなるのか」と聞き、「1日目」から最後の日まで、日で区切って順に見せる。**1本の線**（途中で札を1日目に戻さない）。
- **日の中で見せるのは、変わっていく過程**：使い始めた相手の暮らしと困り事が、日ごとにどう変わるか。小さな兆し → はっきりした変化 → 困り事が無くなった姿。見る人は「自分も、こうなる」を、日を追って見る。
- **日の中で、原因・仕組みを解説しない。** 「なぜ、そうなるか」は、日の後ろ（商品ページ直行の時）か、記事（記事へ送る時）で言う。

## 2. 基盤のまま守る事
**必ず入れる物**
1. だれの話か：書き出しと1日目で、相手の1人の場面を、その人の言葉で（`相手を1人に決める`）
2. 日ごとの変化（3章）
3. 「この日々を実現させたのは、◯◯」の1文（商品の名前）
4. 締め（`中身の質` 10。締めだけ です・ます。札は出さない）
- **着地が商品ページの時だけ、足す物**：商品は何か・原因の1文・商品が原因に何をするか（3章の「日の後ろ」）
- そのほかに守る物：`商品を読む`・`毎回変える物`・`中身の質` の、困り事は一番強い言葉で（2-1）・1文ごとに絵に描ける（2-3）・書き出しの指し方（4-1d）・つなぎの語（8-4）。**守らなくてよい物**：段階の芯の、通る点・厚さの配分・順番・原因の位置・目安の長さ。

## 3. 基盤から変える事
| 何を | 基盤では | この寄せ方では |
|---|---|---|
| 書き出し | 「私の事だ」＋「やばい」の言い切り | **3文**：①だれの話か（場面・している事と、困り事の言葉）→ ②その場所が、今どうなっているか（強く言ってよい）→ ③**つなぎの語（そこで／では／だから）＋型の問い**。問いは30字まで。問いのすぐ次が「1日目。」。前置きを足さない |
| 運び方 | 型が決める | 日で区切る。「◯日目。」は、それだけの1文で、行を分ける。**1週間が基本：1日目 → 2日目か3日目 → 5日目 → 7日目（札は3〜5枚）**。資料に長い時期の話がある時だけ、長くしてよい |
| 1つの日の中 | — | **その日に起きた変化（見える事）→ 相手の感じ・心の声**、の順で 3〜7文。説明の文（なぜ・仕組み・原因の名前）を入れない。後ろの日ほど、変化を大きく |
| 文の調子 | です・ます | 常体で、短く言い切る。**1文＝1つの絵**。文の長さは、中央が15字まで・長くて27字（型の問い・日の後ろ・締めは別） |
| 話し手 | 型が決める | 語り1人。骸骨は、しゃべらない。かぎかっこのせりふは使わない。心の声は、地の文で書く |
| 軽さ | — | 小さい軽さ（物を人のように言う文・自分へのつっこみ）を、1本に1〜3か所 |
| 長さ | 芯の目安 | 記事へ送る時：300〜450字。商品ページ直行の時：450〜700字。句読点・かぎかっこ・改行・札は数えない |

### 日ごとの変化の作り方（どの商品でも）
| 日 | 見せる物 | 相手の感じ |
|---|---|---|
| 1日目 | **小さな兆し**（困り事の起きる所で、前と違う動き・感じが1つ）。**まだ、失敗はある**と正直に言う | 疑い半分。「前とは、何か違う」 |
| まん中の日（1〜2枚） | **はっきりした変化**（前は起きなかった事が、起きる）。困り事の回数が減った、と気づく | おどろき・うれしさ |
| 最後の日 | **困り事が無くなった姿**。相手がしなくなった事・片づけた物を、動作で1〜2つ | 当たり前になった |
- **1日目から、困り事が全部無くなった、と言わない。** 兆しと、まだ残る失敗を、両方言う。
- 変化は、**困り事の起きる所で、目に見える事**で言う（相手か、その相手の物・場所・家族や生き物の、動き）。感じだけの文を続けない。
- **日ごとの変化の材料**：商品の資料の「使った時の話」（初めて使った時・慣れ・続けた時）と、アングルのページの結果の言葉から組む。**どの日に置くかは、書き手が割りふってよい**（資料に日の数が無い時も）。割りふった事は「足した事の一覧」に、日ごとに1行ずつ書く。
- 使い方の決まり（◯回使ったら◯◯する、など）を、その日のする事として1文入れるのはよい。

### 日の後ろ（着地で変わる）
| 着地 | 最後の日の後に、言う順 |
|---|---|
| **記事（この寄せ方の基本）** | ①「この日々を実現させたのは、◯◯（商品の名前）だ」→ ② 商品は何か（1文。使うと、何が起きる物か）→ ③ 残す問い（「なぜ、◯◯だけで、△△のか」）→ 締め（`references/記事と分ける.md` 3章の締めの形）。**原因の名前・仕組みは、言わない**（記事が言う） |
| 商品ページ（直行） | ①「この日々を実現させたのは、◯◯（商品の名前）だ」→ ② 商品は何か（1〜2文）→ ③ 原因の1文（今までの対策で変わらなかった訳）→ ④ 商品が原因に何をするか（仕組み。3〜6文。細部は、資料にある事だけ）→ ⑤ 最後の1文 → 締め。全体の3〜4割まで |
- 数え方：「全体の3〜4割まで」に、締めは入れない。「1つの日は3〜7文」に、「◯日目。」の1文は入れない。字数に、札の「◯日目。」は入れない。
- **1日目の「まだ残る失敗」は、書き手が足してよい**（困り事が、その日も1回起きる、という形で。資料に無くてよい。「足した事の一覧」に書く）。最後の日は「◯日で直る」と言い切らず、その日の朝の姿を言う。
- 着地の指定が無い時は、記事として書き、報告に「着地の指定が無いので、記事へ送る形にした」と書く。
- **最後の1文**（直行の時）は、見る人の最初の1歩を言う（「あなたの1日目は、ここから始まる」の類。言い回しは写さない）。

### 型の問い
| | A 使う側（基本） | B 続ける側 |
|---|---|---|
| 型の問い | 「◯◯（相手の言葉での困り事の場所・場面）に、◯◯（商品の種類の呼び名）を、◯日使うと、どうなるのか」 | 「◯◯（今している事）を続けると、◯日でどうなるのか」 |
| 日で追う物 | 使った日々の変化（上の表） | 続けた日々の変化（悪い方へ。兆し → はっきり → 一番悪い姿）。ここでも、解説はしない |
| 日の後ろ | 上の表（着地で変わる） | 「止める方法は1つ」→ 上の表の ① から |
- 指定が無ければ A。B は、段階①で、相手がまだ商品の種類を探していない時だけ。

**主役（骸骨）が演じる物**
- 骸骨は、**困っている人（相手）**を演じる。主語の無い文は、全部、骸骨がする事・感じる事
- 困り事の起きる場所・相手の物・家族や生き物が、相手とは別にある商品では、それを**同じ画面の物**として置く（骸骨の役にしない）。その物がする文には、その物を主語に書く

## 5. 映像の側が、台本に求める物
台本の出力（`templates/出力の形.md`）の、本文の前に、次の2行を足す。
```
帯：1段目＝<10字まで>｜2段目＝<12字まで>
札：DAY 1／DAY 3／…（本文の「◯日目」と同じ数・同じ順。締めの3文は札なし）
```
本文の後に、**書き出しの替えを2つ**（②だけを替える。①と③はそのまま）と、**帯の替えを2組**足す。

帯は、最初のコマから最後のコマまで、変わらずに出る。見る人が、声より先に読む。
- **1段目**（赤い箱に黒い字）：題材を、一番強く呼ぶ名前。体言止め
- **2段目**（黄色い字）：型の問いを短く。**数を必ず入れ、言い切らずに止める**（「◯日◯◯すると!?」「◯日後どうなるのか!?」）。**数＝最後の札の数**
- 答え（結果・良い悪い）を書かない。書くと、見る理由が無くなる。商品の名前（ブランド名）も入れない。形 A は、商品の種類の呼び名を入れてよい（問いに入っているので）。声での呼び名は、`05_原稿の決まり` のとおり
- 商品が出た後も、うそにならない言葉にする。「世界一」「◯万人」の類は、材料にある時だけ。字数をこえたら、言葉をけずる

## 6. 相性の良い型・合わない型
**型の棚（読む順 5）は、選ばない。** 運びは、この1枚が決める。台帳には「スケルトン寄り・A（または B）・記事（または直行）」と書く。`毎回変える物` は、入口・相手・書き出しの②・日ごとの変化の場面・軽さの置き所・最後の1文、で変える。

## 7. 書いた後の確かめ
1. **書き出し**：3文で、①だれの話か ②今どうなっているか ③つなぎの語＋型の問い（30字まで）か。問いのすぐ次が「1日目。」か
2. **札**：1日目から始まり、戻らず、3〜5枚か。最後の数＝帯の2段目の数か
3. **日の中に、解説が無いか**：日の中の文を1つずつ見て、「なぜ」「原因は」「仕組み・作り」を言う文が0か。あれば、日の後ろへ回すか、消す
4. **過程になっているか**：1日目＝兆し＋まだ残る失敗／まん中＝はっきりした変化と、おどろき／最後＝困り事が無くなった姿、の順か。1日目で全部解決していないか
5. **日の後ろ**：着地のとおりの順か（記事＝名前・何か・問い・締め。原因と仕組みは無し／直行＝名前・何か・原因の1文・仕組み・最後の1文・締め）
6. **数**：長さが着地の幅の中か。文の長さの中央が15字まで・27字をこえる文が、型の問い・日の後ろ・締めのほかに0か。本文は常体、締めだけ です・ます か
7. 日の割りふりを「足した事の一覧」に書いたか。帯に、ブランド名と答えが入っていないか
