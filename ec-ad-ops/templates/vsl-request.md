# VSL の依頼票（ひな形）— pack分けから、台本と映像へ渡す1枚

**1本の動画につき1枚。** 初日の出稿設計（`04_初日の出稿設計.md`。ひな形 `01-pack-split.md`）で pack と本数が決まったら、動画の本数だけ、この票を `<商品名>/06_原稿/依頼票/` に作る。台本のスキル（`vsl-script`）は、この票をそのまま受け取って書く。票に書いていない事は、台本のスキルの決まりで決める。**票に、台本の中身（書き出しの文・たとえ・強い言葉の例）を書かない**（書く人が、それに引っぱられる）。

ファイル名：`<pack>_<通し番号>_<アングル>_<段階>_<映像の型>.md`（例の形：`packB_01_◯◯_②_スケルトン.md`）

## 流れ
1. **pack分け**（工程3）：`04_初日の出稿設計.md` の「動画の依頼」の表（pack・アングル・段階・映像の型・本数）を書く → 本数だけ票を作る
2. **台本**（工程4の前半）：`vsl-script` に票を渡す（「この票で書いて」）。スキルは、`vsl-script/SKILL.md` の読む順のとおりに読んで書き（票のアングルのページ＝J と、**ペルソナのページ＝K** は、「商品を読む」の中で必ず読む。相手の理解シートは K を写して深める）、票の「納める場所」に `台本.md`・`理解メモ.md`・`相手の理解シート.md`・`相手.md` を置き、票の状態に「台本ずみ」と日付を足す
3. **映像**（工程4の後半）：票の映像の型の決まり（`references/video-formats.md` の表）で作る。置いたら、票の状態に「映像ずみ」
3b. **記事**（工程4の終わり）：票の「記事の型」で作る（`references/article.md`・`video-formats.md` の「動画の次は、必ず記事」）。置いたら、票の状態に「記事ずみ」。VSL のビジュアル・場面・登場人物は記事に使わない
3c. **店（PDP）**（記事の次。2026-10-19）：記事の「残った疑い」を受ける商品ページを `pdp-tsukuru` で作る（`references/pdp.md`。商品の事実は `00_入口`・`A`・`02` から）。置いたら「店ずみ」
4. 何本も同時に書かせる時は、`vsl-script` の `templates/何本か書く時の割り当て.md`（票1枚＝書く人1人）

## 映像の型を決める時（pack分けで）
- 1つの pack の中で、映像の型を2つ以上まぜる（型ごとの当たり外れを見るため。運用の決まりは `adops-foundation.md`）
- アングルのページ（J）の「相性の良い映像の型」を見る：スケルトンは、使い始めてからの変化を日ごとに見せる型。着地は記事が基本（2026-10-12）／権威実写は、手に持って見せられる本物がある時／クレイ物語は、相手が「試してきた事」が2〜3つ並ぶ時に向く／ZackDFilms は、どのアングルでも使える／ZackD POV は、困り事を起こしている側（家族・生き物・体の部分）や、今使っている物の目から見ると、訳が分かる時に向く（2026-10-12 足した。ファイル名では `ZackDPOV`）
