## 試作 f1（2026-10-05 の10秒）と変わる所

- **ステージの色**：f1 は水色の格子。zackd-ad は濃い青（ロイヤルブルー）の格子のステージを「実例に近い」として標準にしている（水色は同じ作者の前の版 H-OHI-008a の色）。**zackd-ad の通り＝濃い青**で作る。運営者 が水色を指定した時は、`beats.json` の `style` のステージの色と、編集ファイルの背景色（`AbsoluteFill` の `background`）の2か所だけを水色にする。
- **案内役**：f1 は場面2・3で人が消える。zackd-ad は案内役（買う人）をほぼ全場面に出す。物だけの場面が続くと説明スライドになる。
- **主張はモノにする**：字のラベルで説明する前に、主張そのものを絵の中の物にする（金色の巨大な数字・玉座・石の吹き出し・分かれ道・断面の中に立つ案内役）。言い換えの表は script.md。
- **つなぎ**：f1 は一瞬の切り替え。zackd-ad は push・whip・up・spin・flash を場面ごとに変え、つなぎ方ごとに別のスウッシュを鳴らす。
- **声**：f1 は 1.18倍。zackd-ad は無音を詰めて 1.12倍（`vo.py` の既定。1.15倍までの決まりの内側）。
- **尺**：f1 は10秒。zackd-ad は約1分（470字）〜75秒（560〜600字）。尺の3割強をクローズに使う。

### 1. 台本
- 型は script.md の8段。ただし**言ってよいことは EC 側が先**：商品の `05_原稿の決まり.md`。
- クローズの「使い方 → 保証 → 在庫 → 二択 → 商品名つきのCTA」は、**その商品で言える段だけ**入れる。言えない段は抜く。例：ワンドライは保証の日数も「返金保証」も書かない（05 の 4・10）。抜いた分は「使い方」と「二択」を厚くする。
- 専門家・レビュー・数字の札（見本の「小児科医 ◯◯先生」のような物）は、05 の「記事と人物の表」で使ってよい人がいる時だけ。
- **読みを仮名で固定する言葉**（video-formats.md の「読みの確認」）は、`script.txt` と `plan.json` の `chunks` を仮名で書き、テロップの表記は `plan.json` の `display` で漢字に戻す（例：`"ゆかふきが終わらない": "床拭きが終わらない"`）。編集の `at()` と `HL` のキーは、display を通した後の表記（画面に出る字）で書く。

### 2. 声
- 声は `_rules/音声.md` の表から選ぶ（モデルは `eleven_v4`＝`vo.py` の既定）。v1 は淡々としたナレーション。広告読みにしない。
- 鍵は `（鍵はアプリの接続で管理）` が正。新しいシェルなら環境変数に入っている。前から開いているシェルを使う時は `source （鍵はアプリの接続で管理）` してから `vo.py` を呼ぶ（古い鍵が残っていることがある）。
- `whisper` は `（社内の Mac の道：アプリには無い）`（openai-whisper。2026-10-06 に `uv tool install` で入れた。モデル large-v3-turbo は `（社内の Mac の道：アプリには無い）`）。前からある `whisper-cli`（whisper.cpp）とは別の物で、zackd-ad のスクリプトが呼ぶのはこちら。
- `vo.py` が出す差分（台本→書き起こし）で、音が違うテイクは捨てる。表記ゆれ（仮名と漢字）は差分に出るが音は合っている。読みの確認は video-formats.md の決まりをそのまま当て、新しく間違えた言葉はそこに足す。
- **`vo.py` の後、`build_data.py` の前に必ず `python3 $E/scripts/zackd_align.py $AD` を通す**（文字の時刻を台本の文字そのものに当て直す。ElevenLabs forced alignment）。`vo.py` の時刻は書き起こしと台本の照合で作るので、仮名で固定した言葉で始まる句が遅れる。同じ声で測った句の出だしの誤差：当て直すと平均0.07秒・最大0.16秒、書き起こしのままだと平均0.28秒・最大0.46秒（2026-10-06）。元の時刻は `vo/timing.whisper.json` に残る。

### 3〜5. 場面割り・ステージとキャラ・キーフレーム
- 案内役は買う人（ワンドライなら飼い主と犬）。年齢・髪・服まで書く。商品が映る場面は実物の写真を `kf/product.jpg` に置いて参照に足す。
- 画像に文字を書かせない・主役は上2/3・数を数える絵は編集で並べる、は SKILL.md の通り。
- Higgsfield を使わない決まりの商品（トラベラー）でも、絵は codex なのでそのまま作れる。その時は動画化をせず、全場面を静止画＋編集の動きにする（zackd-ad の72秒の実例は26場面のうち22場面が静止画）。

### 6. 動画化
- Higgsfield は MCP ではなく **CLI** で出す（このMacの MCP は認証で落ちる。CLI は通る）：
  `higgsfield generate create grok_video_v15_lite --start-image $AD/kf/<場面>.png --prompt "<何が動くか＋カメラ>. Smooth, no text, silent" --aspect_ratio 9:16 --duration <秒> --wait`
- 費用は1秒1クレジット（720p。`higgsfield generate cost grok_video_v15_lite --duration 3 …` で3と出る）。**出す前に、動かす場面と合計を 運営者 に伝える**（video-formats.md 手順4）。先に1場面だけ試す。
- SKILL.md の「つまずいた所」のうち media_upload・media_confirm・プリセットの押し売りは MCP の話で、CLI では起きない。

  - `zackd_audio.py` は敷く前に `bgm_check.py` で段と曲（雰囲気台帳の棚と実測）を突き合わせ、合わなければ作らずに止まる。`--override "<理由>"` は 運営者 がその組み合わせを指定した時だけ。どの段にどの曲を敷いたかは `public/_bgm.json` に残る。
  - **おひさまパンツ式に1曲で通す時**は、棚 `7-忍び足・好奇心（Zack D型）` の曲を使う。この棚だけはどの段にも敷ける（型の元の敷きなので、段との突き合わせをしない）。自社の曲は『歩く低音と木の刻みの忍び足BGM』『こもった低音のアルペジオと秒針の忍び足BGM』。
  - **型の元の曲は「Hide and Sneak」（The Fly Guy Five・Epidemic Sound・2021年）**。Starpop のスキルに曲名とダウンロード先が書いてある（こもった低音のアルペジオと秒針・約95BPM。Epidemic Sound の表示は Mysterious・Sneaking）。音ボックスの同じ棚に入れてあるが、**市販の曲で、広告に使うには Epidemic Sound の契約が要る**（`rights_ok: false`。`bgm_check.py` が止める。社内の試作だけ `--override`）。契約を確かめたら雰囲気台帳の `rights_ok` を `true` にする。おひさまパンツの動画にこの録音が入っているかは、照合では確かめられなかった。
 - **機械の判定の限界**：CLAP は「忍び足」と「明るい・コミカル」を聞き分けられない。雰囲気は最後に 運営者 が聞いて決める。
  - **元の見本（H-OHI-008a_v2）の音楽**（声と音楽を機械で分けて測った。耳では確かめていない）：0〜7秒は曲なしで効果音だけ → 7〜47秒は、低い音域を半音ずつ動くベースと刻みが同じ音量で続く（F♯の短調寄り・約92BPM・明るいメロディは無い）→ 19秒の決めの一言で約1秒抜ける → 47秒（先の姿）からベースが消えて軽くなる。問題から商品の説明まで同じ緊張の敷きで通し、曲調が替わるのは先の姿から。zackd-ad の format.md の「こもったベースのアルペジオと刻み」と合う。『半音で動く低音と秒針の緊張BGM』はこれに寄せて作った曲。
  - **スマホで聞こえる曲を優先する。** 低音が中心の曲は、スマホのスピーカーで 10〜15dB 小さくなる（雰囲気台帳の `mood_check.phone_loss_db`。8dB 以上で `bgm_check.py` が注意を出す）。既定の『暗いパッドと心拍の緊張BGM』は −5dB。
  - 「参考由来」の棚は権利未確認なので使わない。
  - **棚に合う曲が無い時は作る**：`python3 $E/scripts/bgm_gen.py <出力フォルダ> <候補.json>`（ElevenLabs `/v1/music`・歌なし指定。候補.json は名前・秒・英語の指示の並び）→ `python3 $E/scripts/bgm_mood.py <曲>` で測る（`uv run --python 3.11 --with librosa --with soundfile --with "torch<2.9" --with transformers`）→ CLAP の1位が棚と合った曲だけ、`07-BGM/`・`雰囲気別/<棚>/`・`雰囲気台帳.json`（`mood_check` つき）・`台帳.json` に登録する。2026-10-06 に15曲作って通ったのは5曲。指示のコツ：`marimba`・`plucks`・`staccato`（短く刻む音）はコミカルに判定される。緊張は伸ばす音で作る（「brooding minor synth pad with slow tremolo・eerie high sustained tone・soft heartbeat pulse・faint ticking・no staccato・no pizzicato・no major chords」）。sub bass だけの曲はスマホで聞こえない。
- 書き出しでヘッドレスChromeが落ちた時は、SKILL.md の「つまずいた所」のラッパーを `REMOTION_BROWSER` に渡す。

### 8. 検品と納品
- 書き出す前：`python3 $E/scripts/sfx_check.py $R/src/<Ad>.tsx --sfx $R/public/sfx`（フックのライザー・無い音）。
- `$K/scripts/render.sh $R <CompositionID> $R/out/<広告名>.mp4 $AD/script.txt`。検品シートを自分で見る（テロップの残り・文字の被り・はみ出し）。
- 足す確認：音量は −13〜−15 LUFS（render.sh の最後の `Input Integrated`）。字幕は高さ 70% 前後まで（zackd-ad は 63%）。誤字・絵の破綻・黒い画面。
- 耳では確かめられない。納品の時に「聞いていない所」を書く（声の読み・BGMとのつり合い・効果音の対応）。BGM は `public/_bgm.json` の中身（どの段に・どの曲を・棚と実測の雰囲気）を表で添え、運営者 が聞いて外した曲は雰囲気台帳の `listened: true, rejected: true` にする。
- 納品は video-formats.md の手順7。

## 長い VSL（3〜5分）を 3D図解で作った実績（2026-10-07・針マット A-1）
- 通った作り方：合格の台本（言葉は変えない）→ 絵コンテの絵（Codex）→ 声（ElevenLabs `eleven_v4`・通しで1本）→ 声の文字の時刻で場面と字幕を割る → 一部の絵を動画化（Higgsfield。MCP がつながらない時は CLI）→ Remotion → 測って検品 → `07_納品/動画/<広告>/` とダッシュボード（`media.json`・preview・サムネ・場面のコマ・plan.json を「作成済み」）
- **長さの見込み**：V4 の読みは約7字/秒（間を詰めた時）。1,760字で4分12秒だった。台本の見込みは「字数 ÷ 7」で出す（÷6.6 だと30秒長く出る）
- **絵の枚数**：1場面は2〜4秒が目安。4分なら**70枚前後**要る。A-1 は34枚で1場面が平均5.6秒になり、条件3つの場面は1枚で18秒あった。絵コンテを作る時に、**「秒数 ÷ 3」枚**を先に割り当てる（長い説明の段は、言う事1つにつき1枚）
- **曲**：段ごとに替える（フックは曲なしでライザー → 原因は緊張 → 放っておくとは冷たい脈 → 解決はほっとする曲 → 締めは前向き）。音量は上の決まり（声より 7〜10 LU 下を測る）
- **読み**：数字や読みが分かれる言葉は、声に渡す文だけ仮名にする（字幕は原稿のまま）。書き起こしで台本と突き合わせる（A-1 は「10分」が「20分」に聞こえて1回録り直し）
- 使った量の実績：Higgsfield 79クレジット（14カット）、ElevenLabs 665（声2回）
