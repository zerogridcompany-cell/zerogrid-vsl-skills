## 3. 絵の窓と、置き方
- 絵とクリップは **9:16** で作る。編集で、**1080×1470 の窓に切り出す**（上 23.44% は帯）。切り出す位置は `--crop-y`（0＝上を残す。試しは 0.2）
- だから、**9:16 の絵の、上 5%・下 20% には、大事な物を置かない**
- **字幕の後ろ（窓の上から 60〜70%）に、顔・エフェクトの芯を置かない。** 光る場所は、胸より上か、字幕より下に。試しでは、腹の光が字幕と重なった（`見本/試し_5秒_コマの並び.jpg`）
- **札が出る場面（日の頭）は、目を、窓の上から 30% より下に置く。** 札は、窓の上から 約20%（おでこ・帽子の上）に出る。試しでは、頭が上すぎて、札が目にかかった

## 4. 場面の割り方とカメラ（15-5 を当てる。違う所だけ）
1. **1場面は 1.2〜2.6秒。** クリップは3秒で打ち、動きのある 1.5〜2.5秒を使う。15-6 の「2.2〜3.2秒」より短い（7章）
2. **1文に1場面。27字に近い文は2場面。**「◯日目」の1文は、次の文と同じ場面の頭（札が出ている間）
3. **1区切りの並び**：①日の頭＝腰から上（場所が分かる）②顔の寄り ③動作 ④光る・中の世界。①→② は、**同じクリップの中の速い寄り**でつないでよい（15-5 の 2）。ほかは切る
4. **切ってよい所が、v1 より多い**：文が変わる所は、切ってよい。場所も時間も同じでも、切る（実物が、そうしている）。15-0 の 3「場所も時間も変わらないのに切っている所 0」は、**当てない**
5. **日が変わる所は、必ず切る。** 切った後の 0.22秒は、道具がぼけた速い寄りを足す（5章）。その場面のクリップに、速い動きを書かない（二重になる）
6. **速い動き（クリップの中）は、1区切りに1回まで。** 顔へ寄る・中へ入る、のどちらか。物の多い場所では使わない（15-5 の 7）
7. **書き出しの3秒は、3〜4場面**（0.7〜1.7秒ずつ）。1コマ目は、顔の寄りで、もう動いている。3秒の所に、エフェクトの絵
8. **終わりは、動いている絵で切る。** 止め絵・終わりの札を足さない。商品が出る場面は 6-4
9. **使い回してよい**：書き出しのクリップを、終わり・折り返しで、もう1度使ってよい（全体の15%まで。続けて使わない）
10. 目の高さ・正面の絵が多くてよい（15-5 の 6「半分まで」は、当てない）。顔の寄りだけ、少し下から・広角

## 5. 帯・札・字幕の作り方（全部、編集で重ねる。絵の中に字を描かせない）
道具：`$S/skeleton_overlay.py`（数は 1-2〜1-4 のとおりに入れてある）。
```
（作業フォルダ：アプリには同梱していない見本） $S/skeleton_overlay.py \
  --video 無音の動画.mp4 --out 出す.mp4 --band1 "<1段目>" --band2 "<2段目>" \
  --days days.json --subs subs.json --crop-y 0.2 [--audio mix.wav] [--check 秒,秒]
```
- `days.json`：`[[秒, "DAY 1"], …]`。秒は、声の「◯日目」の頭。**その秒で、場面が切れている事**
- `subs.json`：`[[始め, 終わり, "かたまり"], …]`。例は `指示の例/`
- 書体：帯と字幕は `fonts/MochiyPopOne-Regular.ttf`（OFL。実物に一番近かった物。実物の書体そのものではない）。札は Arial Black を 0.88倍の幅で。**書体に無い字（◯・一部の記号）は、道具が止める**。言葉をかえる

### 5-1. 帯の言葉（台本に付いて来る。`スケルトン寄り.md` 5章）
**帯の意図**：見る人は、声より先に帯を読む。帯は「何の話か」と「最後まで見ると、何が分かるか」を、ずっと出し続ける。答えは言わない。だから、途中から見た人も、音を出していない人も、最後の日まで見る。
| 段 | 意図 | 決まり |
|---|---|---|
| 1段目（赤い箱・黒字） | **目を止める。** 赤は、画面の中で一番強い色。箱があるので、字より先に、形が目に入る。言葉は「これは、あなたが知らない、強い話だ」 | 8〜10字。体言止め。題材を、一番強い言葉で名付ける |
| 2段目（黄色い字） | **離さない。** 言いさし（「…すと」）か、問い（「…のか!?」）。頭が、続きを欲しがる。数字は「終わりがある」という約束。札が進むたびに、あと少し、と思う | 10〜12字。数字を必ず入れる。**数＝最後の札の数**。答え・良い悪いを書かない |
- 2つの段は、色も形も違う（箱の中の黒字／箱なしの黄字）。同じ形にしない。1段目が「名前」・2段目が「問い」と、一目で分かれる
- 帯は、動かさない・変えない・光らせない。商品が出ても、同じ

### 5-2. 台本に、帯の言葉が無い時（ほかの寄せ方の台本を、スケルトンの映像にする時）
**台本は書きかえない。帯だけを、映像の側で作る。**
1. 1段目：台本の1文目から、芯の名詞を取り、8〜10字の体言止めにする。困り事の名前で呼びかけない台本（段階①）なら、サイン・している事の言葉で
2. 2段目：台本が、最初の3文で聞いている事・言い切っている事を、問いの形にする。「◯◯を放っておくとどうなる!?」「◯◯の本当の原因とは!?」。**台本に無い数字を、作らない**。日の区切りが無い台本では、数字なしでよい
3. 商品の名前・答えを入れない。台本が言っていない事を、帯で言わない
4. 2組作り、強い方を使う。もう1組は、報告に書く（帯だけを変えるテスト用）
5. 日の区切りが無い台本では、**札を出さない**。かたまりの切れ目（8〜12秒ごと）に、ぼけた速い寄りだけを入れる（`days.json` に `[秒, ""]` と書く）

### 5-3. 札
- 字は `DAY 1`（大文字・半角の空き1つ）。台本の「◯日目」と同じ数。折り返しで「1日目」に戻る台本は、札も `DAY 1` に戻る
- 週・月・年で区切る台本は `WEEK 2`・`MONTH 3`（実物には無い。使ったら、報告に書く）
- 出す秒＝声の「◯日目」の頭。出ている長さ 1.7秒（出る 0.27・止まる 1.2・消える 0.23）。次の文が始まっても、出ていてよい
- 札の後ろは、主役のおでこ・帽子（3章）

### 5-4. 字幕
- 声の言葉ごとの時刻（15-0 の 1）から、**4〜11字のかたまり**に切る。意味の切れ目で切る（助詞の後）。12字をこえたら、2つに分ける
- 1行・切りかえ。句読点は出さない。「◯日目」は、それだけで1つ
- 1つのかたまりは 0.4〜1.6秒。次のかたまりの頭まで、出しておく（すき間を空けない）

## 6. エフェクト（v1 の 6章・14-13 の文は、そのまま使える。スケルトン型で足す所）
1. **1区切りに1回以上。** 台本の文が「中で起きている事」を言う所に置く。言っていない所で、光らせない
2. 作り方は2つ。**(a) 体の中が光る・満ちる**：始めの絵（光なし）→ 終わりの絵（EDIT で、光だけ足す。`指示の例/K3.txt`）→ クリップ（`T1.txt`）。**(b) 中の世界に切る**：画面いっぱいの絵を1枚（`K6.txt`）→ その切り出しを終わりの絵にして、ゆっくり寄る（`T3.txt`）。1.0〜2.2秒だけ使う
3. 光の色：水色＝水・流れ・良い変化／赤・だいだい＝熱・痛み・危ない／金＝ごほうび・最後の姿。**1本の動画で、色の意味を変えない**
4. 光は、**終わりの絵に入れると、書いた秒より早く出る**（試しで 0.4秒早い）。声に合わせる時は、クリップの頭を切るか、「出る前」「出た後」に分ける（15-5 の 9）
5. 骨は、光の中でも、すけて見える。体の外に、肉・皮ふを出さない（「No skin, no flesh」を書く）
6. 商品を出す場面（台本の後ろ）：商品の写真を、**1枚目の見本**にして、主役の手に、もう持たせた絵から始める（15-1 の「始めの絵で、もう触っている」）。商品の形・色・ラベルは、写真のまま。新しい字を足さない。**これは、まだ試していない**
