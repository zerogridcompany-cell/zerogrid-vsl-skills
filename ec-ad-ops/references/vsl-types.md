# 話し手のいるVSLの2つの型 — 物語型と直球型

どちらかに統一しない。2つの型を持ち、動画ごとに選ぶ。型で変わる決まりは下の表が正で、ほかの資料の同じ項目より優先する。

- **物語型**：今までの権威VSL。場面と物語で入り、話し手が名乗って長く語る。実例は B-main 第3版（ワンドライ・6分45秒）。作り方は [authority-vsl-production.md](authority-vsl-production.md)。
- **直球型**：最初の一文で結果を約束し、短いカットを速く重ねて、動画の中で証拠・保証・値引きまで言い切る。元は参考動画の実測（[知識ノート](knowledge/2026-10-04-arco-authority-vsl.md)）。作り方はこのファイルと [templates/vsl-direct.md](ec-ad-ops/references/_archive/台本の作り方_20261008/1_VSLの台本の型（14段）/直球型の台本のひな形_vsl-direct.md)。

**VSL（3分以上）の時はこちらを優先：2026-10-07 運営者**（下の2つの型は消していない）
- VSL の台本は、運営者 の指定が無ければ [vsl-script-design.md](ec-ad-ops/references/_archive/台本の作り方_20261008/1_VSLの台本の型（14段）/vsl-script-design.md) の14段（第4版）で書く（4〜5分・ナレーションだけでも書ける。見本 vsl-script-example.md）。物語型・直球型は、運営者 がその型を指定した時に使う
- どの型でも、原因の段は、その商品の `01_商品理解の基盤/H_根本原因.md` の1つを使う（決め方：[root-cause.md](root-cause.md)）。直球型の「物差し＝原因を1つ」も、ここで決めた1つ
- 実写で作る時の手順（画像・動画化・口パク・組み立て）は [live-action-vsl.md](live-action-vsl.md)（リアルの型。2026-10-07 運営者 合格）。物語型・直球型を指定された時も、新しく作る実写の画は realistic-image.md の型
- どの型でも、原因の段にたとえを1つ入れる（アーカイブの vsl-script-design.md の4章）

## 1. どちらを使うか

1. **運営者 が決める**（pack の原稿を出す時に、動画ごとに「物語型／直球型」を書いて承認をもらう）。指定が無ければ聞く。
2. 聞く時に添える目安（**仮説**。根拠は参考動画1本と B-main 1本の作りの違いだけで、配信の実績は無い）：

| こういう時 | 向きそうな型 | 理由（読み取り） |
|---|---|---|
| 着地が記事。動画の役目は「続きを記事で読ませる」こと | 物語型 | 物語型は最後に記事へ送る作り。動画の中でオファーを言い切らない |
| 着地が商品ページ。動画の中で売り切る | 直球型 | 直球型は後半36%で証拠・保証・値引き・在庫まで言う |
| 言える証拠の数字・保証・値引き・期限がある | 直球型 | 後半の段がそれで埋まる。無いと後半が薄くなる |
| 気持ちの話（自分を責めている・後悔）から入りたい | 物語型 | 物語と自責を解く段がある |
| 短い尺で本数を作りたい | 直球型 | 字数が約6割 |

3. 確かめ方：同じ pack に両方の型を1本ずつ入れて比べる（pack の中で変えるのは形式と話し手だけ：基盤 2-3・4B-7）。結果は実績の台帳に書く。1商品の結果で目安を決まりに変えない（基盤 15-3）。

## 2. 型で変わる決まり

| 項目 | 物語型 | 直球型 |
|---|---|---|
| 長さ・字数 | 6〜7分・約2,600字 | 3分30秒前後・約1,500字（1秒に約7字） |
| 段の順番 | authority-vsl-production の1章 | アーカイブの「直球型の台本のひな形_vsl-direct.md」の17段と秒数 |
| 最初の一文 | 場面のフック | 結果＋手間の小ささ＋数字の約束 |
| 名乗り | 5秒以内に名乗る・名前テロップ（原稿の基盤 4-3b） | 名乗らない。肩書は用件の文の中に1回だけ。名前テロップなし |
| 話し手の顔 | 5秒以内 | 冒頭は症状の画と固定の見出し。顔は最初の主張の所で出す（参考は8.6秒） |
| 話し手の出し方 | 長く語る。区間ごと | 1〜3秒を挟む。正面を2回続けない。合計20〜30%。戻るたびに寄りと位置を変える |
| 物差し・枠組み | ループの名前・3つの条件・2つの道を使ってよい | 原因を1つ決め、ほかの対策も商品もそれだけで測る。枠組みの名前を増やさない |
| 字幕 | 話す言葉を全部。白文字に黒フチ（原稿の基盤 4-3f） | 要点の句（4〜12字、です・ますを落とす）。白い箱。言い切りと数字は高い箱 |
| 字幕とカット | カットごとに字幕を区切る | 別々に切り替える。字幕は声に、カットは画の中身に合わせる |
| 悩みの画 | 白黒（チェック表18） | カラー。悩む所に赤い光などの印を重ねる |
| カットの長さ | 2〜3秒ごと・上限4.5秒・1秒以下にしない（チェック表25） | 中央値1.0〜1.5秒。1秒未満も使う。4.5秒超は話し手だけ |
| 同じ種類の画 | — | 続けてよい数：図解8・暮らし5・悩み4・資料3・話し手1 |
| 数字の見せ方 | カード（mg.py） | 画面に文字で重ね、下の画が切り替わっても残す |
| つなぎ | 切り替え・クロスフェード | 前半（問題の段）にブレのつなぎ。後半は切り替えるだけ |
| 画面 | 縦9:16で作り、4:5を切り出す（原稿の基盤 4-3g） | 4:5（1080×1350）で作る。9:16が要る時は `size=(1080,1920)`（字幕は下35%を避けて上がる） |
| 音 | 全体 約−12 LUFS。BGMは声の約10dB下 | 声 −15 LUFS。BGMは声の約17dB下 |
| 編集の道具 | `vsl_auto.Seg`・`vsl_edit.Section`・`vsl_project`・`mg.py` | `vsl_direct.Timeline`・`Lay`・カード3種 |
| 作る前の点検 | script-checklist | script-checklist（上の行で変わる項目を除く）＋ `tl.check()` |

## 3. 型で変わらない決まり（両方に当てる）

- 言った効き目・性能は、撮った実演で見せる（原稿の基盤 4-3e）。
- 締めの決まり（原稿の基盤 4-4）、仮の着地を先に決める（4-0）、矛盾チェック、読みの確認。
- 声：台本全体を1回で読み上げる。口パクは HeyGen。素材庫への登録と納品先（authority-vsl-production 2・3・7章）。
- 検品：黒い画面ゼロ、コマ一覧を目で見る、口パクの確認、聞き取りで文言を照合。

## 4. 直球型の作り方（流れ）

1. **台本**：[templates/vsl-direct.md](ec-ad-ops/references/_archive/台本の作り方_20261008/1_VSLの台本の型（14段）/直球型の台本のひな形_vsl-direct.md) の17段に、行ごとに「読む文・字幕の句・画の種類・重ねる効果」を書く。承認をもらう。
2. **声**：物語型と同じ（1回で読み上げ → 間を詰める → 文字ごとの時刻）。
3. **素材**：行の「画の種類」ごとに用意する。言葉の種類と画の対応は知識ノートの 2-2。
4. **組み立て**：`scripts/vsl_direct.py`。`Lay(tl, rows, 文字の時刻).place()` → `tl.check()` → `tl.render(bgm=…)`。
5. **点検**：`tl.check()` が、話し手の連続・同じ種類の続きすぎ・カットの長さ・字幕の字数を、参考動画の実測と比べて知らせる。
6. **検品・納品・登録**：物語型と同じ。

動作確認（2026-10-04）：`（作業フォルダ：アプリには同梱していない見本）`（B-main 第3版の声と素材を借りた。広告にはしない）
- `test.py`：36秒・4:5。字幕の箱（ふつう・高い）、カットをまたぐ統計とバッジ、中央の数字、赤い光、線と矢印、丸い窓、ブレのつなぎ、色地のカード3種、BGM。黒い画面ゼロ、全体 −14.6 LUFS。
- `test_sync.py`：口パクの映像を `sync=True` で入れ、速さ0.9倍で書き出し。SyncNet は ずれ3コマ・確信度4.5〜5.6 で、道具を通す前の元の映像（ずれ3コマ・確信度5.2）と同じ。縦9:16（1080×1920）でも書き出せる。
- まだ通していない所：台本から声を作る所（ElevenLabs の読み上げ → 間詰め → 文字の時刻）。物語型と同じ関数（`vsl_auto.tts`・`tighten`・`mapper`）を使う想定で、直球型の1本目を作る時に通す。

## 5. 直球型でまだ無いもの（素材の側）

道具は画を並べて重ねる所まで。次の素材の作り方は未整備で、1本作る時に試して決める。

| 要るもの | 今の状態 |
|---|---|
| 同じ話し手の別アングル（寄り・横顔の作業・商品を手に持つ） | 写真1枚の正面だけ。寄りは `punch` で作れるが、横顔と手持ちは人物をそろえた画像の生成が要る |
| スマホで撮ったように見える、カラーの悩む人・暮らしの映像（別の人を何人も） | 今の素材は白黒の作り込んだ画が中心 |
| 3Dの図解（原因と商品の働き） | 平面のカード（mg.py）だけ |
| 実写の上に描く線・骨などの重ね | 直線と矢印は `tl.line`。形に沿った絵は素材ごとに作る |
| 商品の装着・実演の実写 | 商品ごとに撮影か、仕入れ先の映像が要る（生成しない：原稿の基盤 4-3e） |
| 1本160カット分の素材 | 物語型は1本20〜30カット。素材庫の使い回しと並行生成の段取りが要る |
